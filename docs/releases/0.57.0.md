# 0.57.0

0.56.0 이 남긴 후속을 닫습니다. Core pin 은 `0.57.0`.

## 무엇이 달라지나

- **가드 예외는 줄 번호가 아니라 문구로 잡습니다.** 가드 계약의 예외 여섯이 `path:"문구" — 이유` 꼴이 되고, 검사는 그 문구가
  정확히 한 줄에 있고 그 줄이 검사 어휘에 걸리는지 봅니다. 문서가 짧아져도 예외가 어긋나지 않고, 문구가 사라지거나 두 줄에
  나타나면 붉어집니다.
- **경계 요구는 한 곳.** 범위 밖 파일 삭제·이동 금지, 보관된 TESTS 본문 불변(폐기는 프런트매터 세 필드), ARCHIVED_AT 불변 —
  세 프로토콜이 각자 갖던 문장이 `core/contracts/boundaries.md` 로 모였고 프로토콜은 한 줄로 가리킵니다. 규칙 헌법 검사 (b)
  기준선은 빚 0건입니다.
- **PR 도우미의 증거 재실행이 왜 끝났는지 말합니다.** 시간 초과면 제한 초와 설정 키(`SCV_ATTACHMENTS_RERUN_TIMEOUT`)를,
  그 외 실패면 종료 코드를 한 줄에 적습니다. PR 생성은 어느 쪽이든 계속됩니다.
