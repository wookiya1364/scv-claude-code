# 0.101.0

Core 0.101.0 을 싣습니다.

**기어의 입력 · 출력이 보입니다.** 기어 글 맨 위에 `in:` · `out:`(값의 종류 이름)과 `예:`(실제 입력 예 → 출력 예 한 가지)를 적습니다. `/scv:gear` 목록에 기어마다 "받는 값 → 돌려주는 값"과 인자가 나오고, 검사가 그 이름을 첫 · 끝 톱니와 맞춰 봅니다.

**이름 붙은 인자 — 같은 기어를 값만 바꿔 다시 씁니다.** 톱니 사전에 `- 인자: count=12 — 설명` 을 적고 `gear.sh run <기어> count=30` 처럼 줍니다. 값은 사전의 기본값 → 기어 글의 `arg:` 줄 → 실행할 때 준 값 순으로 뒤가 이깁니다. 선언하지 않은 이름을 주면 돌리지 않고 쓸 수 있는 이름을 알려 줍니다(전에는 아무 말 없이 무시했습니다).

**글 대신 그림.** 흐름 · 구조 · 수치 비교를 설명할 때는 그림을 먼저 보여 주라는 규칙이 답 모양에 들어갔습니다. 그림 도구가 있는 세션(데스크톱 앱)에서는 그 도구로 그리고, 없는 세션(터미널)에서는 화살표 한 줄(`A → B → C`)과 짧은 표로 대신합니다. 짧은 답은 글 그대로입니다.

**그림 알림.** 직전 답이 긴 순서 글인데 그림도 화살표 한 줄도 표도 없었으면 다음 턴에 알림 한 줄이 실립니다. 턴을 막지 않습니다. 끄려면 `scv/scv_settings.json` 에 `"SCV_PICTURE_NOTICE": "off"`.

**알아 둘 것.** 0.100.0 에서 만든 기어와 톱니는 고치지 않아도 그대로 돕니다. 기어 실행 한 번은 조금 느려졌습니다(잰 값: 10번에 2.2초 → 2.9초).
