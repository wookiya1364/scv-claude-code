# 0.86.0

Core 0.86.0 을 싣습니다. 계획을 진행하다가 계획에 없던 요구가 나오면, 이제 그 요구를 계획 파일에 남깁니다. 같은 목표면 기존 계획에 단계를 넣고, 다른 목표면 기존 계획을 "보류"로 두고 새 계획을 만들어 연결합니다. 새 계획이 끝나면 원래 계획으로 돌아와 이어서 합니다. 앞뒤로 요건이 충돌하면 아무것도 바꾸지 않고 먼저 묻습니다. 모든 변경은 계획 파일의 "변경 이력"에 한 사건씩 남아, 대시보드를 볼 수 없는 곳(모바일)에서도 왜 멈췄고 어디서 다시 시작했는지 보입니다.

## 올리는 법

```
/plugin marketplace update scv-claude-code
/reload-plugins
```
