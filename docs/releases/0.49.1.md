# 0.49.1

0.49.0 의 "규약은 세션당 한 번" 이 실제로 작동하도록 고칩니다. 들여쓴 명령 예시가 스킬을 펼치는 순간
실행되던 결함을 없앴습니다. Core pin 은 `0.49.1`.

## 무엇이 잘못됐었나

Claude Code 는 SKILL.md 의 `!` 펜스를 모델이 읽기 전에 실행합니다. 코어의 Claude 프로필 변환은 열 0 의
`!` 펜스만 일반 `bash` 예시로 바꿔서, 목록 항목 안에 들여쓴 펜스 8곳(help 2 · workspace 3 · handoff 2 ·
install-deps 1)이 그대로 남아 있었습니다.

- **help**: "규약 전체를 읽었다" 표식(`help-state.sh mark`)이 보조 스크립트의 `PROTOCOL` 줄보다 먼저 실행돼
  표식이 항상 `loaded` — 0.49.0 의 규약 전체 읽기 분기가 어떤 세션에서도 뜨지 않았습니다. /clear 뒤 첫 턴에서
  실측(표식 갱신이 프롬프트 훅 8초 뒤, turn:1 에 protocol:1).
- **workspace · handoff · install-deps**: join/init-root/detach, write/push, `--install` 예시가 스킬을 펼칠 때
  실행을 시도했습니다. 자리표시자(`<URL>` 등) 때문에 대부분 실패로 끝났겠지만, 실행 표면에 노출된 것은 사실입니다.

## 고친 것

- 코어 변환이 앞 공백을 허용해 들여쓴 펜스도 `bash` 예시가 됩니다. 이 래퍼의 SKILL.md 네 파일에서 `!` 펜스가
  모두 사라졌습니다(vendor 핀 PR 에서 확인: `!` 24줄 → `bash` 24줄).
- 코어 검사가 들여쓴 `!` 펜스가 남으면 실패합니다.

설치 뒤 새 세션 첫 턴에 `PROTOCOL: load` 가 찍히고 모델이 `protocols/help/full.md` 를 읽는지, 두 번째 턴부터
`loaded` 인지 확인하세요 — 이번 수정으로 처음 그 분기가 실제로 뜹니다.
