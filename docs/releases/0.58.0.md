# 0.58.0

과정을 재는 계기판이 생깁니다. Core pin 은 `0.58.1`.

## 무엇이 달라지나

- **과정 계기판.** `core/scripts/metrics.sh` 가 이미 디스크에 있는 기록만 읽어 — 아카이브 색인, 계획서, 대화 파일,
  결정 로그 — 지표 넷을 표 하나로 찍습니다: 계획당 대화 턴 수 · 승인→보관 리드타임 · 후속 재발률(구조 신호만) ·
  계획서의 순수함수·파이프라인 절 보유율. 지표마다 적용 범위(n/m)를 함께 찍고, 데이터 없는 계획은 0 이 아니라 none 으로
  분모에만 듭니다. 읽기 전용, 시각·난수·네트워크 없음, 같은 입력에 같은 출력(`--tsv` 로 원자료).
- **계기판이지 제품 통계가 아닙니다.** 각 프로젝트가 자기 파일로 자기를 재는 도구 — 원격 텔레메트리와 새 로깅 훅은 일부러
  넣지 않았습니다. 진단이지 증명이 아닙니다.
- **TESTS 첫 통과율은 이번에 재지 않습니다.** 어디에도 구조적으로 기록되지 않아서 — 후속 계획에서 보관 기록에 한 줄을 더한
  뒤 잽니다.

## 올리는 법

```
/plugin marketplace update scv-claude-code
/reload-plugins
```
