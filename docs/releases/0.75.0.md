# 0.75.0

Core 0.75.0 을 싣습니다. 계획을 구현하는 동안 단계가 바뀌면 SCV 대시보드에 저절로 알립니다 — 대시보드가 0/4 에 멈춰 보이던 일이 없어집니다.

1. **단계 보고**: 구현 중인 계획이 있으면 매 턴 한 줄로, 단계를 시작할 때 · 끝낼 때 · 막혔을 때(이유 한 줄) 대시보드 단계 도구로 알리라고 안내합니다. 이 래퍼는 대시보드 모드의 단계 도구 이름을 설정에 담았습니다 — 모드를 깔지 않았으면 아무 일도 없습니다.
2. **대시보드 단계 상세**: 대시보드 모드 0.2.15 부터 단계마다 쓰는 순수함수와 그 역할(새로 만듦 · 가져다 씀)이 보입니다. 코어는 그 모드가 읽는 순수함수 사전 형식을 시험으로 고정했습니다.

## 올리는 법

```
/plugin marketplace update scv-claude-code
/reload-plugins
```

대시보드 모드도 받으려면 `/scv:mods` 뒤 `/reload-plugins`.
