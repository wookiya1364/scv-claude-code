# 0.30.0

Core 0.30.0 — `.env.example.scv` 자동 최신화와 회귀 러너 환경 위생을 싣습니다.

## 옛 프로젝트도 새 .env 옵션을 발견합니다

지금까지 sync 는 "root 는 user-owned" 원칙으로 프로젝트 루트를 건드리지
않았습니다. 그래서 0.29.0 이전에 hydrate 한 프로젝트는 SCV_EFFORT_MODE 같은
새 옵션의 문서 블록을 영영 받지 못했습니다 — `cp .env.example.scv .env` 하라고
안내받는 바로 그 파일이 hydrate 시점에 얼어 있었습니다.

이제 `.env.example.scv` 하나가 명명된 예외입니다 (hydrate 가 심은 파일이니
SCV 소유). TEMPLATE_VERSION 2.2.0 이 트리거 — 기존 프로젝트는 다음 액션 시작
시 autosync 가 자동으로 갱신하며, 별도 명령이 없습니다. 커밋 안 된 수정이
있으면 기존 장치대로 DIRTY 거부(`--force` 만 오버라이드), 파일이 없으면
재생성, `.env` 자체는 절대 쓰지 않습니다.

## 회귀 러너가 시나리오를 깨끗한 환경에서 돌립니다

러너의 재진입 방지 표시(SCV_AUTOSYNC_RUNNING=1)가 시나리오에 상속되어,
autosync 훅을 검증하는 아카이브 계약이 러너 안에서만 10/11 적색이던 결함을
고쳤습니다. 러너가 시나리오를 실행할 때 그 표시 하나만 지우고(env -u) —
사용자가 export 한 env 는 전부 그대로 전달됩니다. 누적 회귀 11/11 복원.
