# 0.95.0

Core 0.95.0 을 싣습니다.

**바꾼 것 — 고칠 일은 글이 아니라 검사로.**
- 매 턴 싣는 안내 글에서, 검사가 이미 막는 규칙의 설명을 그 검사의 거절 문구로 옮겼습니다. 규칙은 그대로이고, 막힐 때 이유를 읽습니다. 매 턴 글이 472 B 줄었습니다.
- 사용자가 직전 턴의 일을 고쳐 달라고 하면, 고친 뒤 같은 실수를 다시 막을 검사(시험 · 린트 · 훅)로 남길지 선택 창으로 묻게 합니다. 고르기 전에는 파일을 만들지 않습니다.

**바꾼 것 — 계획 끝 검사.**
- 이번 일이 새로 넣은 임시방편 주석(TODO · 임시로 · 나중에 제거 등)을 파일:줄로 알립니다. 막지는 않습니다.
- 순수 함수를 건드린 일이면 순수 함수 사전 검사를 자동으로 돌리고, 같은 일을 하는 함수가 있으면 막습니다.
- TS/JS · 파이썬 · 러스트 함수도 서로의 예시 입력으로 실제로 돌려 비교합니다. 도구가 없으면 "돌려 보지 못함"으로 알립니다.

**바꾼 것 — 단계 보고.** 단계를 끝낼 때는 증거(만든 파일 또는 명령 출력)를, 오래 도는 단계는 로그 파일과 진행 화면 주소를 싣습니다. scv-dashboard 0.2.29 가 증거 없는 끝을 거절하고, 단계를 누르면 증거와 실제 진행을 보여 줍니다.

**그대로인 것.** 답 모양, 다시 쓴 요청 인용, 끝 보고 세 줄.
