# 0.28.0

Core 0.28.0 을 싣습니다. 이 어댑터 자신에게는 두 가지가 옵니다.

## 낡은 템플릿은 다음 액션이 알아서 메웁니다

플러그인을 업데이트하고 리로드하면, 다음에 실행하는 SCV 액션이 프로젝트의 워크플로
문서를 자동으로 최신화합니다. sync 를 따로 부를 필요가 없습니다 — sync 는 수동
재실행과 pre-2.x 대화형 마이그레이션용으로 남습니다.

자동 새로고침은 위로만 갑니다: 동료가 먼저 업데이트한 프로젝트를 옛 세션이
되돌리지 않습니다. 그리고 sync 는 이제 사본을 만들지 않습니다 — git 이 되살릴 수
없는 파일(미커밋 수정·미추적·심링크 등)은 `DIRTY` 로 이름을 불러 거부하고, 거부가
있는 한 완료 도장(버전 스탬프)을 찍지 않으므로 다음 액션이 재시도합니다.

## 그동안 안 돌던 테스트가 CI 에 들어옵니다

`tests/test-guard.sh` 는 이 저장소에서 한 릴리스 주기 내내 34 케이스 중 13 이
빨간 채였고 아무도 못 봤습니다 — 어떤 CI 잡도 그 파일을 돌리지 않았습니다.
Core 0.28.0 이 스위트를 배치 무관으로 만들었고(마지막 케이스가 래퍼 모양 트리에서
자기 전체를 재생합니다), 이제 46 케이스가 여기서 돌고 CI 에 등록됐습니다. 새 스위트
둘(autosync·sync-dirty)도 함께 돕니다.
