# 0.39.0

Core 0.39.0 동기화.

## scv:help 를 대화에서 실제로 강제합니다

지금까지는 매 턴 "help 로 가라"는 안내만 들어갔고, 모델이 그것을 대부분
흘렸습니다. 이제는 **부르지 않고 답을 끝내면 되돌려 세웁니다.**

- **회차마다 요구가 강해집니다.** 같은 문구를 반복하면 같은 실패를 반복하기
  때문입니다 — 요청 → 첫 행동 지정 → 규칙 명시 → 호출 형태 제시 → 최대 강도.
- **포기 로직이 없습니다.** 상한은 호스트가 쥐고, 거기 걸리면 그대로 넘어갑니다.
- **화면에 보입니다.** 매 턴 한 줄로 강제가 켜져 있는지, 직전 턴에 몇 번
  되돌렸는지 알려줍니다. "되는지 안 되는지 모르겠다"가 이 줄로 해결됩니다.
- **되돌리지 않는 경우가 절반입니다.** 스위치를 끈 경우, SCV 를 쓰지 않는
  폴더, 하위 작업자 턴, 이미 다른 SCV 명령이 도는 턴, 그리고 장치가 고장 난
  경우 — 전부 그냥 통과합니다. 판정 근거가 없으면 대화를 막지 않습니다.
- 끄는 법: 설정 파일에서 `SCV_FORCE_HELP=off`. 안내는 남고 되돌림만 멈춥니다.

## 기획서 그림이 겹치고 하나는 비어 나오던 것

두 증상처럼 보였지만 **원인은 하나**였습니다. 그림에 붙는 내부 이름이 시각으로
만들어져, 같은 순간에 그려진 두 그림이 같은 이름을 받았습니다. 뒤진 그림은 앞
그림의 자리를 집어 빈 채로 끝나고, 앞 그림의 색과 화살표는 문서 전체에
번졌습니다.

- 그림마다 **자기 이름**을 갖습니다. 화살표·그림자도 각자 씁니다.
- 이름은 **그림 내용에서** 나옵니다. 같은 그림이면 언제 만들어도 같은 이름이라
  파일이 흔들리지 않고, 중간에 한 장을 끼워 넣어도 나머지 그림은 그대로입니다.
- **빈 그림이 사라집니다.**

- Core pin `0.38.0` → `0.39.0`.
