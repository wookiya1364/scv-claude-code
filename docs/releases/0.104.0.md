# 0.104.0

Core 0.104.0 을 싣습니다.

**오래 도는 일은 뒤에서 돕니다.** Claude 가 오래 걸리는 일을 앞에서 기다리는 동안 새 메시지를 보내면 하던 일이 끊겼습니다(실제 세션에서 200초 대기가 끊김). 이제 60초 이상 기다리는 화면 읽기, 30초 이상 잠자거나 끝날 때까지 도는 기다림 명령은 실행 전에 거절되고, Claude 는 그 일을 뒤에서 돌린 뒤 끝 알림을 받아 이어 갑니다. 끄기: 프로젝트 설정 `SCV_BACKGROUND_FIRST=off`.

**단계의 증거는 눈에 보이는 것입니다.** 계획의 단계를 끝낼 때 내는 증거는 그림 · 영상 · 열어 볼 페이지이고, 소스코드나 글 파일은 증거가 아닙니다. 숫자뿐인 결과도 그림으로 낼 수 있게 막대 그림을 만드는 명령(`evidence-card.sh card`)이 생겼습니다. 화면이 없는 단계는 계획 줄에 적은 순수 함수 목록이 증거입니다.

**같은 일의 반복을 알아챕니다.** 요청이 이미 있는 기어와 겹치면 그 기어로 하라는 한 줄이, 전에 한 요청과 비슷하면 일을 마친 뒤 "기어로 만들어 둘까요?"를 묻게 하는 한 줄이 그 턴에만 붙습니다. 겹치지 않는 턴에는 아무것도 붙지 않습니다. 요청은 비밀 가림 뒤 프로젝트의 기록 폴더에만 쌓이고 커밋되지 않습니다. 끄기: `SCV_GEAR_DETECT=off`.

**원칙 글이 매 턴 실리지 않습니다.** 규칙 글처럼 대화마다 한 번만 전문을 싣고, 대화가 요약 · 재개된 뒤와 경고가 남은 턴에만 다시 싣습니다.

**`/scv:dreams` 를 걷어냈습니다.** 지난 세션을 돌아보는 코칭 보고서 기능입니다. 명령 · 스킬 · 하루 한 번 뒤에서 돌던 실행이 없어졌고, 명령은 22개가 됐습니다. 이미 만들어진 `scv/dreams` 폴더는 건드리지 않습니다 — 필요 없으면 지우면 됩니다.

## 알아 둘 것

- 업데이트는 `/scv:update` 한 번입니다. 새 판은 새 세션부터 쓰입니다(열려 있는 터미널 세션은 `/reload-plugins`).
- SCV 창(scv-dashboard)을 쓰면 0.5.0 으로 함께 올리세요 — 증거를 그림만 받는 것이 이 판의 규약과 짝입니다.
- 기다림 거절은 이 래퍼의 지금 훅 연결로 그대로 걸립니다. 실제 가드에 다섯 가지 호출을 넣어 확인했습니다(200초 대기 거절 · 5초 대기 통과 · 120초 잠자기 거절 · 뒤로 보낸 명령 통과 · 기다림 루프 거절).
- 반복 알아채기에서 "같은 요청을 두 번 했을 때 선택 창이 뜨는 것"은 실제 세션에서 아직 보지 못했습니다. 이미 있는 기어와 겹치는 알림은 실제 세션에서 보았습니다.
