# 0.79.0

Core 0.79.0 을 싣습니다. `SCV_LANG` 을 korean 으로 둔 프로젝트에서 답이 영어로 흐르지 않게 강제합니다 — 매 턴 맨 앞에 언어 규칙 한 줄, 도구를 쓸 때마다 새로 쓴 글을 보고 다른 언어 줄이 있으면 그 자리에서 교정(새 `PostToolUse` 훅), 최종 답이 어긋나면 한 턴에 한 번 막고 그 줄만 고쳐 쓰게 합니다. 사용자가 그 턴에 다른 언어를 요청하면 강제하지 않습니다.

## 올리는 법

```
/plugin marketplace update scv-claude-code
/reload-plugins
```

새 훅은 플러그인을 다시 불러온 뒤 시작한 세션부터 적용됩니다.
