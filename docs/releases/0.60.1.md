# 0.60.1

가이드 원문을 건너뛰었다는 경고가 다음 턴 모델에게 실제로 닿게 고칩니다. Core pin 은 `0.60.1`.

## 무엇이 달라지나

- **"가이드 원문을 안 읽었다" 경고가 이제 모델에게 실제로 닿습니다.** 0.60.0 은 경고를 정확히 만들었지만, 대화를 이어 붙이거나
  압축·재개될 때 경고가 같이 지워져 다음 턴 모델이 보지 못했습니다(설치 뒤 실측으로 발견). 이제 그런 초기화 뒤에도 가이드 경고는 남습니다.
- **경고만 보고도 바로 따라 할 수 있습니다.** 읽어야 할 원문 경로와 읽음 표시 명령을 경고 안에 그대로 담습니다 — 모델이 help 출력을
  걸러 보더라도 놓치지 않게.
- 답을 막거나 고치지는 않습니다 — 경고만.

## 올리는 법

```
/plugin marketplace update scv-claude-code
/reload-plugins
```
