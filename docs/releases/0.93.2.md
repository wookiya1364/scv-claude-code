# 0.93.2

Core 0.93.2 를 싣습니다.

**고친 것 — 단계를 알렸는데도 턴이 끝나지 않던 것.**
- 대시보드(SCV 칸)를 켠 세션에서 계획을 구현하다 보면, 단계 보고 도구로 단계를 알렸는데도 턴 끝 검사가 "단계를 알려라"며 턴을 두 번 막았습니다.
- 그 도구는 앱이 직접 처리해서, 검사가 기대던 "도구 앞 훅"이 돌지 않았습니다. 검사는 부른 턴과 부르지 않은 턴을 가리지 못했습니다.
- 이제 막을 참일 때만 대화 기록에서 이번 턴의 그 도구 호출을 직접 셉니다. 부르지 않은 턴은 지금처럼 막힙니다.
- 평소 턴의 시간은 그대로입니다. 대화 기록이 30MB 일 때 막을 참인 턴만 0.1초쯤 더 씁니다.

**고친 것 — 재는 검사가 일부 함수를 견주지 않고 빼던 것.**
- 순수 함수를 고치면 고치기 전 코드와 시간을 견주는 검사가 돕니다. 이 검사가 다른 파일의 함수에 기대는 함수를 "답이 달라 뺌"으로 내고 견주지 않았습니다.
- 고치기 전 코드를 파일 하나만 꺼내 와서 옆 파일이 없었기 때문입니다. 이제 그 파일이 있는 폴더의 파일들을 함께 꺼냅니다.
