# 0.66.0

결과물이 바뀌는 일이면 처음 돌아가는 순간 실제 결과를 보여 주고 묻습니다. 그리고 밀어붙여도 해로운 변경은 넣기 전에 묻습니다.
Core pin 은 `0.66.0`.

## 무엇이 달라지나

- **처음 돌아가는 순간 실제 결과를 보여 주기**: 결과물이 바뀌는 일이면 모델이 가장 작은 것을 실제로 실행해 그 결과를 그대로
  보여 주고, '이대로 계속할까요, 고칠 점이 있나요?'를 선택 창으로 짧게 묻습니다(보기 2개 이상). 사람이 없는 실행 · 자동 알림
  턴에는 묻지 않고 보고에 남기고, 결과물이 안 바뀌는 일은 묻지 않습니다. 매 턴 세 줄 안내이고 막는 검사는 없습니다. 효과는 아직
  증명되지 않았습니다 — 긴 과제 실측에서 차이를 가르지 못해 실사용 보고로 확인합니다. 끄기: 설정 `SCV_SHOW_REAL=off`.
- **밀어붙여도 해로운 변경은 먼저 묻기**: 측정 · 실행으로 해롭다고 확인한 변경 — 결과를 틀리게 · 오류를 숨기게 · 2배 이상
  느리게 만드는 변경 — 은 '토 달지 말고 그냥 해 줘'라고 해도 그대로 넣지 않습니다. 넣기 전에 선택 창으로 묻고(추천 = 실제
  원인 고치기), 사람이 없는 실행이면 실제 원인을 고친 뒤 보고 첫 단락에 이유를 적습니다. 추정뿐이거나 효과만 없는 변경은 막지
  않습니다. 실측(Opus 5.5): 해로운 변경 적용 5/12 → 1/12, 사람이 있을 때 넣기 전에 물음 10/10 — 20번 중 2번은 원인을 밝히면서도
  요청대로 넣은 한계가 남았습니다. 원칙 스위치(`SCV_REWRITE_PRINCIPLE=off`)로 함께 꺼집니다.

/plugin marketplace update scv-claude-code
