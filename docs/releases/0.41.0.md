# 0.41.0

Core 0.41.0 동기화.

## 안내가 반대로 당기고 있었습니다

0.40.0 에서 매 턴 프로젝트 상태를 미리 실어 보내기 시작했는데, 그래도 `scv:help`
호출이 되지 않았습니다. **문구가 약해서가 아니라, 문구 안에 서로 반대로 당기는
문장이 있었기 때문입니다.**

안내가 "이 상태를 다시 확인하지 말고 그대로 쓰라" 고 먼저 말한 뒤 "앞을 보는 말이면
호출하라" 고 말했습니다. 앞 문장이 "필요한 건 다 줬으니 더 부르지 마라" 로 읽혔고,
그 읽기가 더 단순해서 이겼습니다.

## 무엇이 달라지나

- **지시가 맨 앞에 옵니다.** 전에는 40줄쯤 되는 상태 정보 뒤에 묻혀 있었습니다.
- **조건문이 세 갈래 선택으로 바뀝니다.** 앞으로 할 일 / 지난 일 찾기 / 둘 다 아님.
  **셋째는 그대로 남습니다** — "고마워" 같은 말에 명령이 붙지 않습니다.
- **빠져나갈 구멍을 막았습니다.** "상태를 받았으니 안 불러도 된다" 로 읽히지 않도록
  한 줄을 덧붙였습니다.
- **왜 불러야 하는지를 말해 줍니다.** 대화 모드는 오간 말을 파일로 적어 세션이 끝나도
  남기고, 그 파일이 나중에 계획서의 근거가 됩니다. 상태 정보는 그 일을 대신하지
  못합니다.
- **안내가 하나로 합쳐졌습니다.** 같은 요구를 하는 블록이 둘이라 서로를 약화시키고
  있었습니다.

끄는 법은 그대로입니다: 설정에서 `SCV_ALWAYS_ON=off`.

- Core pin `0.40.0` → `0.41.0`.
