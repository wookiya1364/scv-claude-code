# 0.40.0

Core 0.40.0 동기화.

## 답이 한 번만 나옵니다

0.39.0 은 `scv:help` 를 부르지 않으면 되돌려 세웠습니다. 그런데 그 되돌림은 **답을
다 쓴 뒤에** 걸려서, 되돌릴 때마다 답이 통째로 다시 만들어졌습니다. 토큰이 크게
낭비됐습니다.

지점을 **턴의 시작**으로 옮겼습니다. 이제 프로젝트 상태를 미리 실어 보냅니다.

- **확인하려고 한 번 더 부를 이유가 없어집니다.** 그래서 답은 항상 한 번만
  만들어집니다.
- **되돌림이 사라졌습니다.** 회차마다 세지던 요구, 실패 기록도 함께 없앴습니다.
- **매번 같은 내용은 싣지 않습니다.** 상태 점검 출력의 절반은 SCV 개요와 명령
  목록이고 글자 하나 다르지 않습니다. 그 절반을 빼고 진단만 보냅니다.
- **세 갈래를 모두 인정합니다.** 앞으로 할 일을 말하면 대화 모드로, 지난 일을 찾으면
  아카이브 검색으로 갑니다. **둘 다 아니면 그냥 답합니다** — "고마워" 같은 말에
  액션이 붙지 않습니다.
- **화면 표시줄은 그대로 있습니다.** 준비가 켜져 있는지 매 턴 한 줄로 보입니다.

끄는 법은 그대로입니다: 설정에서 `SCV_FORCE_HELP=off`. 이름은 같지만 뜻이 바뀌었습니다
— 되돌림 강제가 아니라 상태 미리 싣기입니다.

## 곁들여 정리된 것

되돌림이 없어지면서 작업공간 가드가 **다시 홀로 서게** 됐습니다. 0.39.0 에서 붙였던
라이브러리 의존을 걷어, 제품에서 가장 위험한 파일의 위험이 도로 줄었습니다.

- Core pin `0.39.0` → `0.40.0`.
