# 0.73.0

Core 0.73.0 을 싣습니다. 순수함수 사전이 생겼습니다 — 새 함수를 만들기 전에 사전에서 같은 일을 하는 함수를 찾아 다시 씁니다.

- 프로젝트 순수함수 사전: 어떤 언어든 주석에 `@pure 이름` 과 역할 · 종류 · 예를 달면, `pure-catalog.sh build --project` 가 그 저장소의 `scv/core/catalog/pure/` 에 사전을 만듭니다(저장소에 커밋되어 기기 · 협업자가 같은 사전을 봅니다). 같은 언어끼리 같은 입출력이면 중복 의심, 다른 언어끼리는 '다른 언어 짝'으로 서로 적힙니다.
- SCV 자신의 순수함수 247개에 역할 · 종류 · 예시가 붙었고, 진짜 중복(스위치 해석 5개 등)을 합쳤습니다.
- 맥 기본 bash 3.2 에서 깨지던 곳을 고쳤습니다 — 기록 색인 종류 · 결정 이름 · 작성자 이름(대소문자), `[a-z]` 범위.
- 회귀 시험이 같은 시험을 한 번만, 여러 개를 동시에 돕니다 — 코어 저장소 전체 회귀 49분+ 미완 → 18분 21초.
