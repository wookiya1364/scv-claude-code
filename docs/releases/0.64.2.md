# 0.64.2

종료 훅의 세 검사(등록 · 원칙 · 선택지)가 검사마다 한 턴에 한 번씩 막습니다. Core pin 은 `0.64.2`.

## 무엇이 달라지나

- **선택지 검사가 차례를 잃지 않습니다**: 0.64.1 에서는 등록 검사가 먼저 막은 턴에 선택지 검사가 차례를 받지 못해, 글로 된
  결정 표가 화면에 그대로 남을 수 있었습니다(0.64.1 설치본 대화형 재현). 이제 등록 검사가 먼저 막았어도 선택지 검사가 같은 턴에
  한 번 막고 선택지로 다시 묻게 합니다. 원칙 검사(문제 표)도 같습니다.
- **걸린 이유는 함께**: 한 번 멈출 때 여러 검사가 걸리면 이유를 한 번의 막기에 함께 싣습니다(등록 → 원칙 → 선택지).
- 한 검사의 이유는 한 턴에 한 번만 — 그 뒤에도 같은 검사가 걸리면 지금처럼 다음 턴 경고로 넘깁니다. 사람 없는 실행(헤드리스)은
  그대로 막지 않습니다.

/plugin marketplace update scv-claude-code
