# 0.32.0

Core 0.32.0 — PR 과 팀 보고에 붙는 영상·스크린샷이 **이번 기능 것만** 으로 바뀝니다.

## PR 영상은 이번 기능 것만 붙습니다

지금까지는 테스트 결과 폴더에 남아 있는 영상을 전부 붙였고, 그 폴더에는 항상
"마지막 실행"만 남기 때문에 archive 직전 누적 회귀를 돌리면 남의 기능 영상이
PR 에 올라갔습니다. 이제 기본은 이번 계획(슬러그)의 것만입니다 — 파일 경로에
슬러그가 들어 있는 것만 고릅니다(계획별 E2E spec 규약이 출력 폴더 이름을 그렇게
만듭니다). 하나도 없으면 그 계획의 테스트를 한 번 더 돌려 이번 영상을 만든 뒤
붙이고, 그래도 없으면 남의 영상을 붙이는 대신 한 줄로 알립니다.

## 팀 보고도 같은 기준입니다

`/scv:report` 에 `--slug` 를 주면 그 계획의 최신 영상·스크린샷만 올립니다. 안 주면
진행 중인 계획이 딱 하나일 때 그것을 쓰고, 애매하면 예전처럼 최신 파일을 올리며
한 줄로 알립니다. 전부 붙이고 싶은 팀은 `.env` 에 `SCV_ATTACHMENTS_SCOPE=all`.
