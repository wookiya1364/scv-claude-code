# 0.44.0

Core 0.44.0 동기화.

## 답의 모양을 정했습니다

`scv:help` 가 답할 때 쓰는 부분들을 정했습니다 — 결론, 예상 밖의 사실, 항목별 표(지금 ·
바꿀 것 · 규모), 큰 항목만 상세, 속도·비용 같은 가로지르는 얘기, 추천을 붙인 결정 표.
좋은 점검 답에서 그대로 가져온 모양입니다.

## 무엇이 달라지나

- **질문에 맞는 부분만 씁니다.** 짧은 맞장구에는 결론 한두 문장만. 백지 아이디어에는
  결론과 표("지금" 칸은 "없음" — 그것도 사실입니다). 항목 여럿을 점검해 달라면 전부.
  **완성돼 보이려고 부분을 더하지 않습니다.**
- **확인한 것과 짐작을 섞지 않습니다.** 직접 확인한 사실에는 표시가 붙습니다.
- **서로 독립인 결정은 한 표로 묻습니다.** 추천을 붙여서, 번호로 한 줄에 답하실 수
  있게. 앞 답에 따라 다음 질문이 달라지는 경우에만 하나씩 묻습니다.
- **사람의 말로 답합니다.** 규약 안에서 쓰는 이름은 모델용이고 답에 나오지 않습니다.
  대표님이 쓰신 말을 그대로 쓰고, 새 이름을 지어내지 않습니다.

기존의 "쉬운 말 먼저" 규칙은 그대로입니다 — 그 규칙이 결론 문단을, 이번 규칙이 그
뒤를 다스립니다.

- Core pin `0.43.0` → `0.44.0`.
