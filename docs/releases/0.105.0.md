# 0.105.0

Core 0.105.0 을 싣습니다.

**듣기 싫은 말을 다른 말로 바꿔 씁니다 — 새 명령 `/scv:words`.** 읽고 싶지 않은 말과 그 대신 쓸 말을 프로젝트의 낱말 사전(`scv/words/WORDS.tsv`)에 둡니다. 한 줄에 피할 말 · 쓸 말 · 다른 꼴들 · 메모입니다. 대화 첫머리에 사전이 한 번 실리고, 답에 피할 말이 나오면 다음 턴에 `[SCV 낱말]` 한 줄로 알립니다. 이미 보인 답은 다시 쓰게 하지 않습니다. `/scv:words` 로 목록을 보고, `add` · `remove` · `fill`(빈 꼴 채우기)을 붙이거나 "A 대신 B 라고 해"처럼 말로 해도 됩니다. 끄기: 프로젝트 설정 `SCV_WORDS=off`. 명령은 23개가 됐습니다.

**대화를 비운 뒤(`/clear`) 실리는 글이 짧아졌습니다.** 대화 기록의 끝부분만 싣고(12,000자, 턴 머리에서 시작) 전체 기록의 자리를 한 줄로 알립니다. 진행 중 계획 · 최근 결정의 요약 묶음은 싣지 않고 그것을 부를 명령 한 줄만 남깁니다 — 매 턴 글이 진행 중 계획을 이미 알리기 때문입니다. 진행 중으로 표시된 기록이 없으면 3일 안의 가장 최근 기록을 싣습니다.

**비운 뒤 기록이 실리지 않던 것을 고쳤습니다.** 기록 색인을 거르는 일이 줄 수의 제곱으로 느려져 세션 시작 훅이 제한 시간(30초)을 넘겼습니다(282줄에서 274초 넘게). 한 번만 훑도록 고쳐 같은 색인이 0.04초에 끝납니다.

## 알아 둘 것

- 업데이트는 `/scv:update` 한 번입니다. 새 판은 새 세션부터 쓰입니다(열려 있는 터미널 세션은 `/reload-plugins`).
- SCV 창(scv-dashboard)을 쓰면 0.6.0 으로 함께 올리세요 — 창의 낱말 사전 칸과 "기준을 넘으면 요약 대신 비우기"가 이 판과 짝입니다.
- 낱말 사전은 사람이 읽는 글(답 · 진행 알림 · 요약)에만 걸립니다. 코드 · 파일 이름 · 명령 · 사람의 말을 옮긴 글에는 걸리지 않습니다.
- 확인은 시험과 CI 로 했습니다. 실제 세션에서 사전을 넣고 여러 턴을 돌려 보는 확인은 하지 않았습니다.
