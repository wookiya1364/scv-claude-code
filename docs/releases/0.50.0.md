# 0.50.0

규약을 "잊었는지" 모델에게 묻지 않고, 지문과 답 모양으로 잡아 다시 싣습니다. Core pin 은 `0.50.0`.

## 무엇이 달라지나

0.49 는 help 규약 전체를 세션당 한 번만 읽습니다. 남은 위험은 "읽었지만 흐릿해진" 상태였는데, 모델의 주의는
잴 수 없습니다. 이번 판은 행동으로 판정합니다 — 통신의 체크섬과 재전송 요청처럼.

- **규약 지문 메아리** (`SCV_HELP_ECHO`, 기본 on). 규약 전체를 읽은 턴에 `help-state.sh mark` 가 8자리 무작위
  지문을 만들어 표식과 `scv/journal/.help-nonce` 에 씁니다. 지문은 규약을 읽은 컨텍스트에만 있습니다 — 스킬
  본문·훅 출력·`PROTOCOL` 줄에는 없습니다. 모델은 매 턴 대화 기록의 Turn 머리 아래에 `protocol: <지문>` 한 줄을
  적습니다. `Stop` 훅이 그 줄을 표식과 비교해 없거나 다르면 표식을 되돌리고, 다음 턴 첫머리에 `[SCV 규약 지문]`
  한 줄과 함께 규약 전체를 다시 읽습니다. 빠진 뒤 다시 실리기까지 최대 10턴 → 다음 턴.
- **답 모양 린트** (`SCV_ANSWER_LINT`, 기본 on). `Stop` 훅이 직전 답의 골격만 봅니다 — 첫 문단 문장 수
  (`SCV_PLAIN_MAX_SENTENCES` 상한) · 결론 없이 표/목록으로 시작 · 첫 문단의 코드값(백틱 안 경로·버전·설정 키) ·
  결정표(`| # |`)의 추천 열 비어 있음. 벗어나면 다음 턴에 `[SCV 답 모양]` 한 줄 + 규약 재읽기. 답을 막거나
  고치지 않습니다 — `Stop` 훅은 여전히 non-blocking.
- **관찰 로그** `scv/journal/.help-drift`(ignore 대상): 턴마다 한 줄. 세션 뒤 "흐려진 턴" 수를 셀 수 있습니다.

## 훅이 쓰는 파일

`scv/journal/` 아래 넷 — `.help-state`(표식) · `.help-nonce`(지문) · `.help-warn`(다음 턴 경고, 훅이 싣고 지움) ·
`.help-drift`(로그). 전부 ignore 대상이며, 스위치 둘을 끄면 `Stop` 훅은 저널 외 아무 것도 쓰지 않습니다(0.49 동작).

설치 뒤 확인할 것: 새 세션 첫 턴에 규약을 읽은 뒤 대화 기록에 `protocol:` 줄이 붙는지, 그리고 `/clear` 뒤
첫 턴에 규약을 다시 읽는지(지문은 그때 새로 만들어집니다).
