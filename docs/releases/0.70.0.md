# 0.70.0

SCV 안에서 scv-mods 모드를 설치 · 업데이트 · 삭제합니다. 세 명령 모두 인자가 없습니다. Core pin 은 `0.70.0`.

## 무엇이 달라지나

- **`/scv:mods`**: 설치된 모드를 전부 업데이트한 뒤 목록을 보여 줍니다. 묻지 않고 바로 돌고, 업데이트 전후 버전을 함께 알려 줍니다.
- **`/scv:mods-install`**: 설치할 수 있는 모드를 선택 창에 띄웁니다. 고르면 설치하고, 이미 설치된 모드를 고르면 업데이트합니다.
  모드 마켓(`wookiya1364/scv-mods`)이 없으면 먼저 추가합니다.
- **`/scv:mods-remove`**: 설치된 모드를 선택 창에 띄웁니다. 맨 앞 보기는 '모두 그대로 두기'입니다.
- 비공개 저장소라 인증에 실패하면, 설치됐다고 말하지 않고 `gh auth login` 다음 `gh auth setup-git`(또는 SSH 키) 안내를 냅니다.
- `/reload-plugins` 안내는 모드 목록이 실제로 바뀐 때만 나옵니다.
- `/scv:update` 는 그대로입니다(SCV 자체 업데이트만).

## 올리는 법

```
/plugin marketplace update scv-claude-code
/reload-plugins
```
