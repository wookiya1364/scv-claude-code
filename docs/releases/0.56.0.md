# 0.56.0

어제 계획서 셋이 "나중에" 로 남긴 여섯 건을 닫습니다. Core pin 은 `0.56.0`.

## 무엇이 달라지나

- **결정 로그 규칙은 한 곳.** 계획 승인(promote)·보관(work)·폐기(regression)이 각자 길게 갖고 있던 설명 단락이
  `core/contracts/decisions.md` 로 모였습니다. 세 프로토콜은 스크립트 호출 한 블록과 자기 엔트리 블록만 갖습니다. 엔트리
  헤더와 "author 필수" 는 그대로입니다.
- **자동 갱신이 파일을 건너뛸 때 커밋을 안내합니다.** 규칙 파일에 커밋 안 된 수정이 있어 갱신이 거부(DIRTY)되면, PARTIAL
  머리줄과 드리프트 설명 한 줄이 "그 파일의 변경을 커밋(또는 되돌리기)하면 다음 액션이 갱신한다" 고 말합니다. 거부는 여전히
  거부입니다 — 강제 덮어쓰기는 없습니다.
- **규칙 헌법 검사 (b) 에 허용목록.** 같은 블록을 모든 프로토콜에 일부러 찍는 것(쉬운 말 절 · 언어 설정 포인터 · 훅 머리말)이
  중복 후보로 잡혀 기준선을 채우고 있었습니다. 키와 **이유** 를 적은 허용목록으로 빠지고, 기준선은 11건에서 진짜 빚 3건으로
  줄었습니다. 이유 없는 줄은 검사가 거부합니다. (벤더링된 사본에서는 (b) 를 건너뛰므로 래퍼에는 영향이 없습니다.)
- Graft 지원 언어 목록은 README 와 대조해 일치(23개 언어)를 확인했고, `no-graph` 의 `graft init` 안내는 0.55.0 에 이미 있어
  코드를 더하지 않았습니다. "대화가 있는 액션" 7개 범위는 사용자 결정으로 유지합니다.
