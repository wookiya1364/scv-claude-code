# 0.74.0

Core 0.74.0 을 싣습니다. 글이 휴대폰에서도 덜 헤매게 읽히도록, 글쓰기 글 네 편에서 추린 규칙 여덟 가지를 넣었습니다 — 묻는 횟수는 그대로입니다.

1. **통과 기준 경고**: 시험서의 통과 기준에 값이나 정확한 문구가 없으면 구현 시작 때 경고합니다(막지 않음).
2. **README 길이 검사**: 표 칸 · 문단이 휴대폰 한 줄 · 한 화면을 넘으면 막습니다. 이 저장소 README 도 그에 맞게 줄였습니다.
3. **좁게 묻기**: 처음 실물을 보여 줄 때 "글자가 다 읽히나요?"처럼 볼 곳을 짚어 묻습니다.
4. **개요 먼저**: 계획서를 쓰기 전에 열 줄 안팎의 개요를 확인받고, 그 확인이 곧 승인입니다.
5. **글 모양**: 결론 한 문장 → 요점 → 자세히, 굵게는 줄 머리에만, 번호 목록, 남은 일에 맡은 사람, 내용 있는 제목.

## 올리는 법

```
/plugin marketplace update scv-claude-code
/reload-plugins
```
