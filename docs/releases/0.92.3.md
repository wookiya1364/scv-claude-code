# 0.92.3

Core 0.92.3 을 싣습니다.

**고친 것.**
- 일하는 도중에 말을 보내면 그 턴의 계획 기록이 0 으로 돌아가던 것. 턴 끝 검사가 사람의 말마다 턴을 새로 시작해서, 그 앞에 남긴 기록을 한 번 더 요구했습니다. 계획을 보관한 뒤에 말을 보내면 예외를 적어야 턴이 끝나기도 했습니다. 이제 앞 턴이 끝나지 않았을 때 온 말은 같은 턴으로 이어집니다(요청 번호와 기록이 그대로 남고, 새 말은 요청 글 뒤에 붙습니다).
- 턴을 멈춘 뒤에 보낸 말도 이어지는 턴으로 봅니다. 그래서 멈추기 전에 고친 파일도 턴 끝에 기록을 요구합니다. 끝난 턴 뒤의 말은 예전처럼 새 턴입니다.

**코어 쪽 정리.** 시험 실행기가 시험이 남긴 배경 프로그램을 끝냅니다 — 뒤에 오는 시험이 2배 넘게 느려지던 원인이었습니다. PR 검사의 맥 조각을 다섯에서 일곱으로 늘렸습니다.

**이 저장소의 검사.** 맥 검사의 시간 한도를 6분에서 10분으로 올렸습니다(리눅스는 6분 그대로). 같은 일이 맥 러너에 따라 142 ~ 340초 걸리고 380초로 끊긴 적이 있습니다.
