# 0.60.2

가이드 경고에 원문 경로와 읽음 표시 명령이 빠지던 것을 고칩니다. Core pin 은 `0.60.2`.

## 무엇이 달라지나

- **"가이드 원문을 안 읽었다" 경고에 읽을 원문 경로와 읽음 표시 명령이 빠지던 것을 고칩니다.** 새 대화의 첫 턴처럼 규약을 새로 읽는
  턴에서 이 줄들이 지워졌습니다(설치 뒤 실측으로 발견). 경고가 다음 턴에 닿는 것 자체는 0.60.1 실측에서 확인했습니다 — 모델이 경고를
  보고 원문을 읽고, 다시 쓴 요청을 답에 보였습니다.

## 올리는 법

```
/plugin marketplace update scv-claude-code
/reload-plugins
```
