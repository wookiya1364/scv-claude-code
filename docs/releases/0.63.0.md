# 0.63.0

다시 쓴 요청에 SCV 원칙이 붙고, 배경 작업 완료 알림은 더 이상 새 턴을 열지 않습니다. Core pin 은 `0.63.0`.

## 무엇이 달라지나

- **SCV 원칙**: 다시 쓴 요청 끝에 `[SCV 원칙 적용 — 단위 표 · 문제 표]` 표식이 붙고, 모델은 원칙 전문을 받습니다 — 듣기 좋은 말 대신
  사실, 풀 문제는 단위 표(단위 · 해결책 · 추천 · 생길 수 있는 문제)와 문제 표(번호 · 위치 · 조건 · 깨지는 것 · 확인)로, 표 한 행은
  터미널 한 줄 폭으로. 끄려면 설정 `SCV_REWRITE_PRINCIPLE=off`.
- **배경 작업 알림은 사람 턴이 아닙니다**: 배경 작업 완료 알림(`<task-notification>`)이 오면 새 턴 · 등록 요구 · 종료 차단 · 안내 블록
  없이 지나갑니다. 다음 사람 메시지부터 평소대로입니다.
- **PR 대상 브랜치**: `/scv:work` 가 여는 PR 은 설정 `SCV_PR_BASE`(예: `develop`) 로 갑니다. 비우면 원격 기본 브랜치(예전과 같음).
- **PR 커밋 범위**: 작업 기록 · 대화 · 결정 기록이 보관 폴더와 같은 커밋에 올라갑니다. 커밋 안 된 코드가 남아 있으면 PR 을 만들지 않고
  목록을 보여 줍니다.
- **맥 기본 셸(bash 3.2)**: 매 턴 훅의 턴 세기 · 진단 줄이기와 진단 아래쪽(자료 · 계획 개수)이 제대로 나옵니다.
- CI 가 루트 README 만 바뀐 PR 에도 돌고, README 검사(명령 · 설정 실재, 세 언어판 일치)를 맥 · 리눅스에서 돌립니다.

## 올리는 법

```
/plugin marketplace update scv-claude-code
/reload-plugins
```
