# 0.46.0

Core 0.46.0 동기화 + 배경 조사 에이전트.

## 깊은 질문은 배경 조사로 — 세션 노력 단계는 그대로

사람마다 세션의 노력 단계(effort)가 다르고, 높을수록 답이 늦습니다. 그렇다고 SCV 가 그
단계를 대신 낮추지는 않습니다 — 0.45.0 에서 모델을 두고 내린 결정과 같습니다. 대신 **깊은
질문만 배경 조사에 넘깁니다.** 답은 지금 세션 그대로 나가고, 깊은 결과는 파일로 남아
뒤따릅니다.

## 무엇이 달라지나

- **기본은 꺼짐입니다.** 아무 것도 달라지지 않습니다. 켜려면 설정 파일에
  `SCV_DELEGATE_EFFORT` 를 `on` 으로 두세요 (켜는 값은 `on` 뿐입니다).
- **켜면** 매 턴 안내에 한 블록이 더 실립니다: 답은 지금 세션 그대로, 여러 파일을 읽거나
  검증이 필요한 질문은 배경 조사 에이전트에 넘기고, 결과 전문은
  `scv/raw/<날짜>-research-<주제>.md` 로 남습니다. 알림에는 요약만 옵니다 — 알림 본문은
  잘리기 때문입니다.
- **새 에이전트 `scv-investigator`** 를 함께 싣습니다. 배경으로 돌고, 세션 모델을
  상속하며, 노력 단계를 지정하지 않고, 편집 도구가 없습니다. 어떤 SCV 명령도 이 에이전트를
  자동으로 부르지 않습니다 — 답하는 모델이 깊다고 판단한 턴에만 뜹니다.
- **세션의 노력 단계는 어디서도 바뀌지 않습니다.**

- Core pin `0.45.0` → `0.46.0`.
