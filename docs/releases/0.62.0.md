# 0.62.0

매 턴 요청을 지금 모델의 추천 프롬프트 요구 항목과 1:1로 비교하고, 빠지면 같은 턴에 바로잡습니다. Core pin 은 `0.62.0`.

## 무엇이 달라지나

- **매 턴, 모든 메시지를 지금 모델의 추천 프롬프트 요구 항목과 1:1로 비교합니다.** 공식 가이드 원문에서 뽑은 모델별 요구 항목 목록(목표 ·
  배경 · 끝 조건 · 범위 · 결과물 · 멈출 때 등, 항목마다 원문 인용)을 함께 싣습니다. 짧은 메시지도 예외가 없습니다.
- 모델은 항목마다 "메시지에 있음 · 맥락에서 채움(출처) · 해당 없음 · 물음" 을 정해 SCV 에 등록하고, 다시 쓴 요청을 답 바로 앞에 인용한 뒤
  그것으로 일합니다. 못 찾은 것 중 가장 중요한 하나만 추천 답과 함께 되묻습니다.
- **확실한 보장**: 등록 전에는 파일 수정이 거절되고, 등록이나 인용 없이 턴을 끝내려 하면 한 번 되돌려 마저 하게 합니다.
- 요구 항목 목록의 인용이 원문과 글자 그대로인지 CI 가 검사합니다.
