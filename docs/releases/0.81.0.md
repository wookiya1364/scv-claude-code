# 0.81.0

Core 0.81.0 을 싣습니다. 이름 있는 함수는 모두 순수(`@pure` — 역할 · 종류 · 예) 또는 부수효과(`@effect` — 이유 한 줄)를 선언해야 하며, 선언 없는 새 함수를 쓰는 편집은 거절됩니다(sh · ts/js · py · go, 하위 에이전트 포함). 목록 검사는 선언 없는 함수가 기준선보다 늘면 실패합니다. 회귀 시험이 컴퓨터를 덜 잡아먹도록 겹쳐 도는 시험 묶음 안은 하나씩 돕니다.

## 올리는 법

```
/plugin marketplace update scv-claude-code
/reload-plugins
```
