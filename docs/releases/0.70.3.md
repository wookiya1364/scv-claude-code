# 0.70.3

계획서의 모든 단계가 '하는 일'을 적게 됐습니다. 함수를 만들지 않는 단계(시나리오 · 시험 실행 · 녹음 등)는 단계 줄 끝에 하는 일 한 줄을 적습니다. Core pin 은 `0.70.3`.

## 무엇이 달라지나

- 함수를 만드는 단계 줄은 0.70.2 처럼 끝에 `` — `단계` `` 로 파이프라인 표와 잇습니다.
- 함수를 만들지 않는 단계 줄은 끝에 ` — <하는 일 한 줄>`(백틱 없이)을 적습니다.
- scv-dashboard **0.2.5** 가 이 한 줄을 단계 흐름의 '하는 일'로 보여 줍니다. 실제 계획서(6단계)에서 전에는 4단계가 비었습니다.

## 올리는 법

```
/plugin marketplace update scv-claude-code
/reload-plugins
```

대시보드는 `/scv:mods` 로 0.2.5 를 받습니다.
