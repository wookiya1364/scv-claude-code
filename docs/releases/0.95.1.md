# 0.95.1

Core 0.95.1 을 싣습니다.

**고친 것 — 긴 세션에서 턴 끝 검사가 끊기던 일.**
- 긴 세션에서 턴 끝 확인이 몇 분씩 걸려 종료 훅이 60초 한도에 매번 끊겼습니다. 그동안 다시 쓴 요청 인용 검사도 돌지 않았습니다. 큰 목록 비교를 한 번 훑는 방식으로 바꿔, 그런 세션의 상태에서 180초 넘음 → 2.4–4.5초가 됐습니다.
- 이 세션이 쓴 파일 목록에 같은 경로가 쌓이지 않습니다(한 세션 44만 줄 → 서로 다른 파일 수만큼).
- 종료 훅이 판정 전에 끊겨도 다음 말은 새 턴으로 시작합니다. 일하는 중 온 말과 막힌 뒤 이어지는 턴은 지금처럼 같은 턴입니다.
- 턴 끝 확인이 30초를 넘으면 통과시키고 '확인 생략' 한 줄을 기록합니다.

**그대로인 것.** 판정 규칙(막음 · 통과), 답 모양, 다시 쓴 요청 인용.
