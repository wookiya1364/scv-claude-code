# 0.42.0

Core 0.42.0 동기화.

## 갱신은 이미 자동이었습니다

플러그인을 갱신한 뒤 `scv:sync` 를 손으로 치고 계셨다면, 그럴 필요가 없었습니다.
**자동 갱신은 예전부터 돌고 있었습니다.** 다시 불러온 뒤 첫 액션이 배포본과 프로젝트
문서를 비교해, 다르면 그 자리에서 새로고침합니다. 번호가 그대로고 내용만 바뀐
릴리스도 지문으로 잡아냅니다.

손으로 치게 만든 것은 둘이었습니다.

- **안내가 반대로 말했습니다.** 코어 규약은 "다시 불러오면 첫 액션이 알아서 닫는다"
  인데, 래퍼 안내는 "sync 를 따로 실행하라" 고 시켰습니다.
- **갱신됐다는 증거가 화면에 안 남았습니다.** 자동 갱신은 결과를 알리는데 그 보고가
  훅에서 통째로 버려졌습니다. 조용히 지나가니 "정말 됐나" 싶어 한 번 더 치게 되는
  구조였습니다.

## 무엇이 달라지나

- **갱신된 턴에는 한 줄이 보입니다.** 워크플로 문서를 새로고침했다는 보고가 지시
  블록 바로 뒤에 실립니다. 일부만 갱신됐거나 실패했을 때도 그대로 말합니다.
- **갱신할 것이 없으면 아무 말도 하지 않습니다.** 침묵이 기본값입니다 — 평소 턴의
  출력은 한 줄도 늘지 않습니다.
- **안내를 코어 규약에 맞췄습니다.** 이제 update 안내가 sync 를 시키지 않습니다.
  `scv:sync` 는 손으로 다시 돌리는 길과 2.0 이전 프로젝트의 이관 경로로 남습니다.

갱신을 판단하고 실행하는 로직 자체는 손대지 않았습니다. 바뀐 것은 보고 경로와
문구뿐입니다.

- Core pin `0.41.0` → `0.42.0`.
