# 0.51.2

매 턴 비용을 줄이고, 그래프를 SCV 가 직접 만듭니다. Core pin 은 `0.51.2`.

## 무엇이 달라지나

- **답 모양 검사는 이번 턴의 답만 본다.** 턴 종료 훅이 호스트가 넘긴 마지막 답 본문(`last_assistant_message`)을
  1순위로 씁니다 — 대화 원본은 비동기로 적혀 한 턴 전 답을 보던 문제를 없앴습니다. 원본은 턴 경계에서 짧게
  재시도하고, 없으면 그 턴 검사를 건너뜁니다. 드리프트 줄 끝에 `src=host|transcript|none`. 따옴표·괄호 안
  마침표는 문장으로 세지 않습니다.
- **매 턴 라우터 다이어트.** help 스킬 본문 9,670B → 7,115B(−26%). 진단이 바뀐 턴의 preflight 에서 매번 같은
  안내문("Learn more"·hydrate 방법)을 뺐습니다(3.3KB → ≈1.5KB). 상한 검사로 잠갔습니다.
- **SCV 자체 그래프 — graphify 제거.** `graph.sh build|status|ensure|impact|report` 가 문서 링크·보관 계획이
  건드린 파일·결정 참조·함께 바뀐 파일 쌍을 bash + jq 만으로 `scv/.graph/` 에 만듭니다(무시 파일, 낡으면 자동
  재생성). 구현·회귀 앞단에 "이 파일을 바꾸면 무엇이 같이 바뀌고 어느 계획·결정이 얽혔는가" 가 실립니다.
  그래프 스킬 설치가 더는 필요 없고, 계획 수립에서 그래프 갱신을 묻지 않습니다. 호스트 프로필의
  `SCV_GRAPH_SKILL_PATHS` 는 받아도 무시합니다(폐기).
- **Graft 어댑터(선택).** `graft` 가 있고 `graft/` 그래프가 있으면 회귀 앞단에 정적 영향 범위, 구현 헤더에 관련
  코드 후보를 덧붙입니다. 없으면 `GRAFT_STATUS: absent` 한 줄뿐. SCV 는 설치·init·훅을 하지 않습니다.
- 패치 0.51.1 · 0.51.2: 코어 검사의 저장소 전용 항목은 scv-core 에서만 보도록(벤더링 사본에서 붉던 것).

## 수령

`/scv:update` → marketplace update → `/reload-plugins`(재시작 없이 훅·스킬이 바뀝니다).
