# 0.89.1

Core 0.89.1 을 싣습니다(0.88.2 · 0.88.3 · 0.89.0 의 변경 포함).

**권장 effort 요청(새 기능).** 모델마다 공식 프롬프팅 가이드가 권하는 effort 값이 있습니다. 세션의 effort 가 그 값과 다르면 SCV 가 한 번 묻습니다 — 지금 값, 권장 값, 가이드의 문장을 함께 보입니다. 바꾸는 것은 사용자이고 SCV 도 모델도 값을 바꾸지 않습니다. 같은 조건은 그 프로젝트에서 한 번만 묻고, 세션의 첫 턴에는 묻지 않습니다. 모델 9개의 권장 값과 근거 문장은 `prompting/EFFORT.tsv` 에 있습니다. 끄려면 `scv/scv_settings.json` 에 `"SCV_EFFORT_RECOMMEND": "off"`.

**잘못된 거절 셋을 고쳤습니다.** 기록 폴더(`scv/raw` · `scv/journal` 따위)를 다른 저장소로 연결해 둔 프로젝트에서 기록 파일만 바꾼 턴이 막히던 것, 진행 메모가 계획의 '하지 않음' 항목과 낱말 하나만 같아도 거절되던 것(이제 항목 낱말의 절반 이상일 때만), 연결된 원자료 폴더를 옮기기가 거절하던 것.

**맥 기본 bash(3.2)에서 그래프가 죽던 것을 고쳤습니다.** 계획이 가리키는 파일이 없을 때 생기던 오류입니다.
