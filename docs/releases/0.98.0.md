# 0.98.0

Core 0.98.0 을 싣습니다.

**새로 생긴 것 — 코드 주석 없이 순수 함수 사전이 원본(기본 켬).** 업데이트하면 다음 사람 턴에 한 번, 프로젝트 코드(sh · ts/js · py · rs · go)의 주석을 순수 함수 사전(`scv/core/catalog/pure`)으로 옮기고 코드에서 지웁니다 — 함수 표식은 사전 항목으로, 부수효과 함수는 `effects.md`, 그 밖의 설명 · 도구 표시 줄은 `notes.md` 로. 커밋은 하지 않으니 결과를 보고 직접 커밋하세요(되돌리기: `git checkout -- .`). 그 뒤로는 코드에 주석을 넣는 편집과 사전에 없는 새 함수가 거절됩니다. 문자열 · 정규식 안의 `#` · `//` 와 스크립트 첫 줄 `#!` 는 건드리지 않습니다. 끄려면 설정에 `SCV_CATALOG_SOURCE=off` 를 적거나 `/scv:catalog-source` off.

**새로 생긴 것 — `/scv:catalog-source`.** 인자 없이 켜고 끄기를 뒤집거나 on/off 로 정합니다. on 은 그 자리에서 옮기고, off 는 주석 막기만 풉니다(사전은 그대로).

**고친 것.** 매 턴 규칙 글이 대화 요약 · 답 모양 어김 뒤에 계속 전부 실리던 일 — 이제 한 번 실은 뒤에는 한 줄입니다(실제 세션 재생: 한 줄 턴 1 → 26 / 73).

**알아 둘 것.** 함수 위에 `@pure` 주석이 있어야 한다고 검사하는 시험이 프로젝트에 있으면, 옮긴 뒤 그 시험은 사전을 보게 바꿔야 합니다.
