# 0.70.4

계획서 단계 줄이 '하는 일'을 말하지 않으면 작업 시작 때 알려 줍니다. Core pin 은 `0.70.4`.

## 무엇이 달라지나

- 작업(work)을 시작할 때, `Suggested path` 줄 가운데 끝에 `` — `단계` `` 연결도 ` — <하는 일 한 줄>`도 없는 줄, 또는 파이프라인 표에 없는 이름을 쓴 줄을 `PLAN_LINK:` 경고 한 줄로 알립니다.
- 모델은 그 줄을 알리고 계획서 그 줄에 꼬리를 채운 뒤 구현합니다. 막지는 않습니다.
- 그래서 scv-dashboard(0.2.5 이상) 단계 흐름에서 단계마다 '하는 일'이 빠지지 않습니다.

## 올리는 법

```
/plugin marketplace update scv-claude-code
/reload-plugins
```
