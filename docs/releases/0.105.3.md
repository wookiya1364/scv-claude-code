# 0.105.3

README 를 지금 판에 맞췄습니다. 동작은 바뀌지 않았고, Core 는 0.105.1 그대로입니다.

**README 에 대시보드 절이 생겼습니다.** 데스크톱 앱의 SCV 창(scv-dashboard)을 설치하는 법, 쓰는 법, 실제 화면을 찍은 이미지를 세 언어 판(영어 · 한국어 · 일본어)에 넣었습니다. 지금까지는 "설치" 절 안의 네 줄이 전부였습니다.

**"쓰는 법"과 설정 표를 채웠습니다.** SCV 가 매 턴 하는 일에 끝 보고의 확인 범위, 묻기 방식, 반복 알아채기(기어), 낱말 사전을 더했고, 그 설정 키 여섯 개(`SCV_FINISH_REPORT` · `SCV_ASK_MODE` · `SCV_GEAR_DETECT` · `SCV_WORDS` · `SCV_CATALOG_SOURCE` · `SCV_BACKGROUND_FIRST`)를 설정 표에 넣었습니다.

## 알아 둘 것

- 플러그인의 동작은 0.105.2 와 같습니다. 이 판은 문서만 바뀌었습니다.
- 화면 이미지는 실제 세션의 SCV 창을 찍은 것입니다. 폴더 경로는 저장소 이름만 남겼습니다.
- `scv-hello` 가 `scv-dashboard` 로 바뀌었다는 안내는 README 에서 뺐습니다. 옮기는 법은 [scv-mods 의 README](https://github.com/wookiya1364/scv-mods#update)에 그대로 있습니다.
