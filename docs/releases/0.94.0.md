# 0.94.0

Core 0.94.0 을 싣습니다.

**바꾼 것 — 답의 모양.**
- 굵은 주제 아래에 불릿 없는 줄로 결론을 한두 문장 먼저 씁니다. 지금까지는 첫 불릿이 결론이었습니다.
- 이유가 이어지는 생각("A 라서 B, 그래서 C")은 불릿 하나에 문단으로 이어 씁니다. 지금까지는 불릿마다 한 가지씩만 써서 이음말이 빠졌습니다.
- 서로 따로인 항목(상태 목록 · 남은 일 · 확인 범위 세 줄)은 지금처럼 불릿마다 한 가지씩 씁니다.
- 끝말은 그대로 '~함 · ~임'입니다. 문단 길이는 숫자 대신 이유로 적었습니다 — 휴대폰 한 화면에 들어오게.

**바꾼 것 — 답 검사.**
- 불릿 아래로 이어 쓴 줄을 그 불릿의 글로 셉니다. 지금까지는 줄글 문단으로 세어 "줄글이 길다"는 경고가 났습니다.
- 아주 긴 불릿과 존댓말로 끝난 결론 줄은 다음 턴에 경고로 알립니다. 막지는 않습니다.

**그대로인 것.** 표 규칙, 다시 쓴 요청 인용, 끝 보고 세 줄, 글 모양 안내를 끄는 설정과 줄글 문장 상한 설정.
