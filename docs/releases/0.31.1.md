# 0.31.1

Core 0.31.2 — 기록 훅이 한글을 반으로 자르던 결함을 고친 패치 핀입니다.

## 일지가 항상 온전한 UTF-8 로 남습니다

어시스턴트 답변을 팀 일지에 남기는 훅은 답변 꼬리를 바이트 단위로 잘라
붙였습니다. 한글·일본어·이모지는 한 글자가 3–4바이트라 그 자리에서 글자가
반으로 잘렸고, 일지 첫머리에 남은 깨진 바이트 하나 때문에 편집기가 파일 전체를
다른 인코딩으로 읽어 "한글이 다 깨진" 것처럼 보였습니다(실제 프로젝트에서 59KB
중 1곳). 이제 자른 뒤 반쪽 시퀀스를 떨어냅니다 — 정상 글자는 한 자도 잃지
않습니다. 이미 깨진 일지는 그 바이트 하나를 지우면 정상으로 읽힙니다.
