# 0.67.0

사용자가 검토 시점을 정해 둔 일에서는 그 시점에 요약 대신 실제로 돌린 결과를 보여 주고 묻습니다. Core pin 은 `0.67.0`.

## 무엇이 달라지나

- **검토 시점에 실제 결과 보여 주기**: "구현 한 덩어리마다 커밋하고 검토 요청"처럼 언제 보여 주고 물을지를 정해 두었으면, 모델은
  그 시점을 앞당기지 않고 그때 요약 대신 실제로 돌린 결과(명령 출력 · 함수 호출 결과)를 그대로 보이며 선택 창으로 묻습니다. 돌려
  볼 수 없으면 못 돌린 이유를 한 줄로 밝히고 묻습니다. 사람이 없는 실행 · 자동 알림 턴은 그대로입니다(묻지 않고 보고에 남김).
  실측(긴 과제 6개 × 세 방식): 검토 시점 줄을 뺀 과제에서 켬 6/6 · 끔 3/6 이 편집 뒤 실제 결과를 보이고 물었고, 검토 시점이 있는
  원래 과제는 6/6 이 커밋 뒤 검토에서 실제 결과를 보였습니다 — 커밋 전 설계 질문에 결과를 곁들인 1건이 '앞당김'으로 남은
  한계입니다. 끄기: 설정 `SCV_SHOW_REAL=off`.

## 올리는 법

/plugin marketplace update scv-claude-code
