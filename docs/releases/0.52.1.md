# 0.52.1

Graft 를 처음 실제로 설치해 보고 잡은 결함 셋. Core pin 은 `0.52.1`.

## 무엇이 달라지나

- **코드 대조가 실제로 동작합니다.** 0.51.0 에서 Graft 어댑터를 붙일 때 Graft 의 응답 모양은 문서화돼 있지
  않아 흔한 두 모양으로 추정했고, 이 저장소는 셸 스크립트라 실물로 확인할 수 없어 그대로 나갔습니다. 실제
  응답은 다른 모양이었고, 그래서 코드 후보가 **한 건도** 잡히지 않았습니다 — 오류 없이 조용히. 이제 실물 모양을
  먼저 읽고, 기존 추정 둘은 다른 판을 위해 남겨 둡니다.
- **변경 지도가 그래프를 저장소 뿌리에서 찾습니다.** 계획 폴더에서 찾고 있어, Graft 가 설치돼 있어도 없는 것으로
  떨어져 코드 대조 열이 전부 비었습니다.
- **검사가 "Graft 없음" 을 가정하지 않고 만듭니다.** 경로에서 낱말만 걸러내는 방식은 전역 설치본을 놓칩니다.
  개발 기계에 설치하자 항목 넷이 붉었습니다. 이제 필요한 도구만 모은 디렉터리를 만들어 그 상태를 확실히 만듭니다.
- 실물 Graft 가 있을 때만 도는 검사 넷을 더했습니다. 가짜 도구로는 "우리가 상상한 모양을 읽는다" 까지만
  확인되고, 이번에 빈 것이 바로 그 자리였습니다.
