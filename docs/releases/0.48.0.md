# 0.48.0

help 가 매 턴 싣는 양이 줄어듭니다. 동작은 그대로입니다. Core pin 은 `0.48.0`.

## help 의 매 턴 비용이 17k 토큰에서 6~7k 로

help 는 매 턴 강제로 불립니다. 지금까지는 한 턴에 규약 본문 28KB, 보조 스크립트 출력 10KB,
훅 주입 5KB 가 실렸습니다. 세 가지가 바뀝니다.

- **분기 전용 본문은 부속 파일로.** hydrate 제안 · 언어 첫 설정 · 옛 대화 이사 · archive 검색 ·
  promote 넘김이 `protocols/help/*.md` 다섯 파일로 갔습니다. 본문에는 앵커 제목과 "지금 읽어라"
  한 줄만 남아, 그 분기에 들어갈 때만 읽힙니다. 이 래퍼는 바뀐 것이 없습니다 — 부속 파일은
  기존 벤더링·투영 경로로 그대로 실려 옵니다(`protocols/` 트리 통째, 자리표시자 치환 포함).
- **보조 스크립트의 대화 모드 출력은 파싱 머리만.** 진단·배너는 훅이 이미 매 턴 싣고 있어 중복
  이었습니다. archive 목록은 새 `--archive-index` 플래그로 archive 검색 분기에서만 받습니다.
- **상한 검사.** 본문 ≤14,000B · 매 턴 스택 ≤18,000B 를 코어 검사가 지킵니다. 투영본 기준 실측:
  SKILL.md 29,292B → 14,051B.

설치 뒤 `claude plugin details scv@scv-claude-code` 로 help 의 on-invoke 값을 한 번 재 보세요.
0.47.0 에서 약 11.1k 였습니다.

## run-dry 의 문장 고정에 이유가 붙습니다

코어 회귀 검사에서 규약 문장을 그대로 고정하던 앵커 중 코칭 문구만 보는 32개와 중복 3개가
빠지고, 남는 문장 고정 118개에는 `# why:` 가 붙었습니다. 새 검사 `tests/test-anchor-intent.sh`
(순수부 `tests/lib/anchors.sh`)가 벤더링되어 이 래퍼 CI 에서도 돕니다. 규약 본문 변경은 없습니다.
