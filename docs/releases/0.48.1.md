# 0.48.1

help 부속 파일의 명령 경로를 고친 패치입니다. Core pin 은 `0.48.1`.

## 부속 파일 안의 명령이 그대로 돌아갑니다

0.48.0 에서 help 규약의 분기 본문 다섯이 `protocols/help/*.md` 부속 파일로 갔는데, 그 안의 명령이
플러그인 루트 자리표시자를 쓰고 있었습니다. SKILL.md 본문은 호스트가 로드할 때 그 자리표시자를
절대 경로로 바꿔 주지만, 부속 파일은 평문으로 읽혀 바뀌지 않고 셸 환경에도 그 변수가 없습니다.
모델이 경로를 추론해야만 명령이 돌았습니다.

- 부속 파일의 명령은 이제 `<plugin root>/scripts/…` 로 적히고, 머리에 "`<plugin root>` 는 이 파일의
  두 단계 위" 한 단락이 있습니다. 이 래퍼에서는 플러그인 캐시 루트, Codex 에서는 벤더 코어 루트입니다.
- 코어 검사가 부속 파일에 자리표시자가 남으면 실패시킵니다.

동작 변경은 없습니다. 0.48.0 의 매 턴 비용 절감(help on-invoke 약 11.1k → 5.2k 토큰)은 그대로입니다.
