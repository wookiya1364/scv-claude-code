# 0.103.0

Core 0.102.0 과 0.103.0 을 싣습니다.

**기어를 시킨 턴이 가벼워집니다.** 저장해 둔 기어를 돌리라는 요청(`/scv:gear run <기어>`, 또는 SCV 창이 붙인 기어 한 줄이 있는 글)은 가벼운 길로 갑니다. Claude 가 도움말을 부르고 요청을 등록하고 긴 끝 보고를 쓰는 대신, 값만 확인하고 기어를 돌린 뒤 두세 줄로 답합니다. 작은 새 프로젝트에서 같은 요청을 한 번씩 재 보니 모델 호출 8 → 2번, 쓴 토큰 2,814 → 379, 72초 → 20초였습니다. 기어를 말하기만 한 글이나 없는 기어 이름은 보통 턴입니다. 끄려면 `scv/scv_settings.json` 에 `"SCV_GEAR_TURN": "off"`.

**결정은 선택 창으로 나옵니다.** 데스크톱 앱에서는 Claude 가 결정을 선택 창 대신 답 아래의 마무리 상자에 질문과 버튼으로 넣는 일이 잦았습니다(실제 세션 134턴 중 33턴). 이제 마무리 상자에 질문을 넣으려 하면 그 자리에서 거절되고, Claude 가 선택 창부터 띄웁니다. 답 글이 나오기 전에 잡으므로 선택 창이 늦게 뜨지 않습니다. 선택 창이 전보다 자주 뜹니다 — 덜 묻게 하려면 `/scv:ask-mode ends`.

**그림을 더 자주 그립니다.** 흐름 · 구조 · 숫자 비교는 그림 먼저라는 규칙(0.101.0)이 있었지만, 그림 도구가 있는 세션에서도 표와 화살표 한 줄로 갈음하는 일이 많았습니다(규칙이 실린 22턴 중 그림 2턴). 이제 그림 도구가 있으면 그 도구로 그리라고 못 박았고, 흐름을 화살표 줄로만 보인 답에는 다음 턴에 알림 한 줄이 실립니다. 끄려면 `"SCV_PICTURE_NOTICE": "off"`.

**서로 어긋나던 지시를 정리했습니다.** 열 곳입니다. 예: "글로 물으면 거절된다"던 안내는 사실대로(상자 질문은 거절, 글 질문은 알림) 고쳤고, 진행 중 계획의 단계를 알리라는 안내는 그 계획을 다루는 턴으로 좁혔고, 릴리스만 한 턴이 단계 보고 때문에 막히던 일을 없앴고, 앞에서 돌린 검사의 결과를 읽어 "통과"라고 적으면 알림이 뜨던 것을 풀었습니다.

**값이 필요한 기어는 값을 물어봅니다.** 인자나 입력값이 있는 기어를 값 없이 시키면 Claude 가 선택 창으로 값을 하나씩 안내합니다. 기본값이 첫 보기이고, 요청에 이미 적은 값은 묻지 않습니다.

**알아 둘 것.**
- SCV 창(대시보드 0.4.0)은 기어를 Claude 없이 직접 돌립니다 — 값을 창에서 정하려면 이 판이 필요합니다.
- 기어 실행기는 실행이 끝날 때마다 저널에 한 줄(기어 이름 · 인자 · 종료 코드)을 남깁니다.
- 기어 턴에서도 파일 쓰기는 다른 턴과 똑같이 검사합니다.
