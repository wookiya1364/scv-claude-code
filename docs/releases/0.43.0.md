# 0.43.0

Core 0.43.0 동기화.

## 선택지를 준 것이 문제였습니다

0.41.0 에서 지시를 맨 앞으로 옮기고 명령문으로 바꿨는데도 `scv:help` 가 잘 불리지
않았습니다. 원인은 문구가 아니라 **세 갈래를 준 것 자체**였습니다.

블록이 "셋 중 하나를 고르고, 고른 것을 실행하라" 고 말했고, 셋째 갈래가 "아무 것도
부르지 말라" 였습니다. **아무 것도 하지 않는 것이 정답인 경우가 명시돼 있었던
셈입니다.** 애매한 말 앞에서는 부르는 쪽보다 침묵이 언제나 더 쉽고, 그래서 애매한
턴은 전부 그쪽으로 샜습니다.

## 무엇이 달라지나

- **지시가 명령 하나가 됩니다.** "답을 쓰기 전에 이 메시지 전문을 인자로 help 를
  지금 호출하라. 판단하지 말고 부르라." 고를 것이 없으므로 샐 곳도 없습니다.
- **판단은 help 가 합니다.** 부를 필요가 있었는지는 인자를 손에 쥔 쪽이 정합니다.
- **부르지 않는 경우는 둘뿐입니다.** 이미 SCV 명령이 실린 턴, 그리고 사람이 쓰지
  않은 자동 알림. 분류가 아니라 정의상 해당 없는 경우입니다.
- **help 도 돌려보내지 않습니다.** 초안에는 "남길 게 없으면 그냥 끝" 갈래가 있었는데,
  그건 출구를 옮겼을 뿐 없앤 게 아니어서 뺐습니다.
- **짧은 턴은 파일을 새로 만들지 않습니다.** "고마워" 같은 말도 기록은 남되, 이
  세션이 쓰던 대화 파일에 이어 붙습니다.

지시 블록이 21줄에서 13줄로 짧아졌습니다. 끄는 법은 그대로입니다:
설정에서 `SCV_ALWAYS_ON=off`.

- Core pin `0.42.0` → `0.43.0`.
