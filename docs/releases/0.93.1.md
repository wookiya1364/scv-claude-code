# 0.93.1

Core 0.93.1 을 싣습니다.

**고친 것 — 넘겨받은 계획에도 마무리 보고가 생깁니다.**
- 다른 저장소가 넘겨준 일을 받아 계획을 만들면(`/scv:promote` 의 넘겨받기) 계획 문서와 시험 문서만 생겼습니다. 마무리 보고가 없어서 그 계획은 "이 기능 전에 세운 계획"으로 취급되어 보고 없이 보관됐습니다.
- 이제 마무리 보고 틀 `WRAPUP.md` 가 함께 생기고, 다른 계획처럼 보고를 다 채워야 보관됩니다. 틀의 언어는 프로젝트 언어 설정을 따릅니다.

**더한 것 — 지난 작업 찾기가 마무리 보고도 찾습니다.**
- "배운 것"이나 "원인"에 적은 말로 그 계획을 찾을 수 있습니다. 결과에는 종류가 "마무리 보고"로 나오고, 번호는 줄이 아니라 묶음 번호(1 ~ 7)입니다.
- 묶음 제목 · 칸 이름 · 안내 글처럼 모든 계획에 똑같이 있는 말로는 걸리지 않습니다.

**고친 것 — 낱말 끝 조사를 떼다가 글자가 깨지던 것.**
- 계획의 "하지 않음" 항목과 겹치는지 볼 때 "버튼을"을 "버튼"으로 만드는 함수가, 컴퓨터의 언어 설정이 UTF-8 이 아니면 글자를 반만 잘랐습니다.
- 이제 언어 설정과 셸에 상관없이 같은 답을 냅니다. 이 함수를 부르는 명령은 전부터 UTF-8 설정을 스스로 골라 쓰고 있어서, 대부분의 컴퓨터에서는 달라지는 것이 없습니다.
