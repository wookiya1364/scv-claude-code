# 0.70.1

모드 이름 `scv-hello` 가 `scv-dashboard` 로 바뀐 것에 맞췄고, 이름이 바뀐 직후 모드 명령이 막히던 흐름을 고쳤습니다. Core pin 은 그대로 `0.70.0`.

## 무엇이 달라지나

- **`/scv:mods-install`**: 모드 마켓을 먼저 새로 받은 뒤 보기를 띄웁니다. 옛 목록 때문에 새 이름(`scv-dashboard`)이 보이지 않던 문제가 없어집니다.
- **`/scv:mods`**: 마켓에서 이름이 바뀌었거나 빠진 모드는 업데이트하지 않고 `renamed <새 이름>` · `gone` 으로 알려 주며, 새 모드를 설치하는 법을 안내합니다.
- 모드 마켓은 공개 저장소입니다. 모드를 찾지 못한 실패에 `gh auth login` 안내를 잘못 붙이지 않습니다(마켓 자체를 못 읽은 때만 냅니다).
- 설명서 · 명령 예시의 모드 이름이 `scv-dashboard` 입니다.

## scv-hello 를 쓰던 경우

`/scv:mods-install` 로 `scv-dashboard` 를 설치합니다. 목록에 `scv-hello` 가 남아 있으면 `/scv:mods-remove` 로 지웁니다.

## 올리는 법

```
/plugin marketplace update scv-claude-code
/reload-plugins
```
