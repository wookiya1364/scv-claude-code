# 0.97.0

Core 0.97.0 을 싣습니다.

**새로 생긴 것 — 가벼운 루프(SCV_LEAN_LOOP=on, 기본 꺼짐).** help 부르기 · 요청 등록 명령 · 규약 읽음 표시 · 대화 기록 쓰기를 모델 대신 훅이 합니다. 등록은 답 맨 위 `> **다시 쓴 요청**:` 인용에서 읽고, 계획 기록 검사는 턴을 막지 않고 기록만 남깁니다. 같은 두 턴 과제 비교에서 장부 호출 10–12 → 0, 읽은 입력 약 1/7, 시험 결과는 같았습니다.

**새로 생긴 것 — 처음과 끝만 묻기(SCV_ASK_MODE=ends, 기본 all).** 요구 · 계획 개요, 끝 검증(영상 · e2e), 되돌릴 수 없는 일만 묻고 중간 결정은 추천대로 정해 끝 보고에 남깁니다. 설정 파일 · 환경 변수, 또는 새 명령 `/scv:ask-mode` 로 켜고 끕니다(인자 없으면 뒤집기, `ends`/`all` 지정 가능).

**고친 것.** 규약을 다시 읽는 턴마다 규칙 글이 두 턴 연속 전부 실리던 일.

**그대로인 것.** 두 설정을 켜지 않으면 매 턴 안내와 검사는 0.96.0 과 같습니다(훅 출력 바이트 비교).
