# SCV Claude Code 0.21.0

Released: 2026-08-04

## Core 0.21.0 sync

- The pinned SCV Core moves to `0.21.0` (`vendor/scv-core/VERSION`,
  `core.lock`). All changes below are Core-owned; the Claude adapter seam is
  unchanged and all 14 actions remain as they were.

## Raw-doc lifecycle (unused vs consumed)

- `action:promote` Step 8 now consumes its raw sources: originals move
  (content unchanged) into `scv/raw/stale/` and `scv/readpath.json` v2 records
  which promote slugs used each doc (`ref_docs`, accumulated across features,
  plus `ref_commit`/`consumed_at`/`origin`). Files still directly under
  `scv/raw/` are therefore exactly the never-promoted **unused** docs.
- `action:status` shows the unused/consumed split and flags consumed docs that
  mention repo files changed since consumption (`OUTDATED-CANDIDATE`);
  `action:help`'s banner surfaces the unused count.
- Mixed-version caution: a pre-0.21.0 wrapper's `readpath.sh update` rewrites
  the state file without `ref_docs`. Update Claude Code and Codex wrappers
  together on shared projects.

## Deck diagrams: readable and offline-ready

- Architecture mermaid diagrams in generated 기획서 decks were near-invisible
  (white init-palette edges on the light diagram card). The doc renderer now
  ships contrast overrides and the promote protocol's `%%{init}%%` template
  aligns with the deck theme tokens, so diagrams stay readable in both light
  and dark themes.
- After the doc build, `deck.sh` bakes every diagram into the HTML as inline
  SVG via a locally installed headless Chrome — the deck opens fully rendered
  with no CDN at view time. Best-effort: without Chrome or network the deck
  keeps the CDN + text-fallback rendering (`--no-static` / `SCV_DECK_STATIC=0`
  to opt out).
