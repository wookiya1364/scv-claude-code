# 0.88.0

Core 0.88.0 을 싣습니다. 요청을 다시 쓰는 법을 그 모델의 공식 프롬프팅 가이드 하나로 줄였습니다. 매 턴 요청을 요구 항목 표와 하나씩 견주던 단계와 낱말 규칙을 없앴고, 등록은 이 턴에 바꿀 대상(범위)과 다시 쓴 요청 두 줄만 받습니다. 등록 전 파일 쓰기 거절, 다시 쓴 요청 인용이 답 맨 위에 없을 때의 종료 차단은 그대로입니다. 사실 말하기 · 해결책 표 · 해로운 변경은 먼저 묻기 같은 SCV 원칙은 다시 쓴 요청에 붙지 않고, 같은 문구를 매 턴 안내가 싣습니다.

Fable 5.2 · Sonnet 5.5 · Haiku 5.5 의 공식 프롬프팅 가이드를 새로 싣습니다. 이제 이 세 모델의 세션도 자기 모델의 가이드를 읽고 요청을 다시 씁니다. 가이드가 없는 모델은 공통 가이드만 읽습니다.

## 올리는 법

```
/plugin marketplace update scv-claude-code
/reload-plugins
```
