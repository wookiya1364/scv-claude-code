# 0.68.0

실사용 보고가 '실제 결과를 보이고 물었나'를 바르게 셉니다. Core pin 은 `0.68.0`.

## 무엇이 달라지나

- **실사용 보고 판정기**: 기록 구조로 확실한 턴(편집 → 실행 → 그 출력을 글에 그대로 인용 → 선택 창이나 끝 물음표 질문)은 규칙으로
  세고, 결과를 보인 뒤 물음표 없이 끝난 애매한 턴(예: "리뷰 부탁드립니다. 고칠 점이 있으면 말씀해 주세요")만 판정자에게 묻습니다.
  이 래퍼는 판정자로 Sonnet 을 도구 없이 · MCP 없이 · SCV 를 끈 채 부르는 `scripts/show-real-judge.sh` 를 싣습니다(시간 제한
  `SCV_JUDGE_TIMEOUT` 초, 기본 300). 판정자는 보고(`scripts/show-real-report.sh`)를 돌릴 때만 불리고, 애매한 턴마다 보인 출력 한 줄과
  끝 글의 마지막 1,500자만 20턴씩 갑니다. 답은 사용자 캐시에 저장해 같은 턴을 다시 묻지 않습니다. 실측(가린 새 표본 40턴): 잘못
  잡음 0 · '보이고 물음' 19/20(규칙만이면 6/20) · 판정자 입력 애매한 턴당 1,346토큰.
- **거절된 확인 창**: 보기가 모자라 사람에게 보이기 전에 거절된 선택 창은 물은 것으로 세지 않습니다. 사람이 보고 닫은 창은 물은
  것으로 셉니다.
- 판정자를 부르지 못하면(로그인 없음 · 사용 한도 · 시간 초과) 보고는 멈추지 않고 그 턴을 '판정 못 한 턴'으로 숫자만 냅니다.
- 매 턴 안내 · 계약 문구 · 스위치는 그대로입니다.
