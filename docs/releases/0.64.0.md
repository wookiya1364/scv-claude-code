# 0.64.0

SCV 가 고르게 하는 결정이 다시 고르는 선택지(객관식)로 뜹니다. Core pin 은 `0.64.0`.

## 무엇이 달라지나

- **결정은 선택지로**: 계획 폴더 이름 · 제목 · 빈틈 질문 · 회귀 삭감처럼 SCV 가 사용자에게 고르게 하는 결정이 글 속 표 대신 고르는
  선택지로 뜹니다 — 결정 하나에 질문 하나, 첫 보기가 추천, 보기마다 그 보기를 고르면 생길 문제를 막는 방법. 질문이 4개를 넘으면 나눠
  연달아, 보기가 4개를 넘으면 두 단계로 묻습니다(모델 정책 질문이 이렇게 바뀌었습니다). 답이 글로 묻고 끝나면 종료 훅이 같은 턴에 한 번
  막고 선택지로 다시 묻게 합니다. 끄려면 설정 `SCV_CHOICE_GATE=off`.
- **헤드리스 실행**: `claude -p` 처럼 사람이 답할 수 없는 실행에는 선택지 도구가 없어서, 예전처럼 번호 표로 묻고 막지 않습니다.
- **SCV 원칙은 단위 표 하나로**: 표식은 `[SCV 원칙 적용 — 단위 표]`, 단위 표는 '단위 | 해결책 | 추천' 세 칸 — 해결책이 그 방법이 부를
  문제를 막는 길까지 담고, 문제 표 · '생길 수 있는 문제' 칸은 없습니다(답에 넣으면 종료 훅이 한 번 막습니다).
- **긴 턴 · 스킬 불러오기**: 다시 쓴 요청을 보인 뒤 계획 단계를 불러오거나 턴이 길어져도 앞서 보인 인용을 인정합니다(예전에는 끝내기를
  잘못 막았습니다).
- **맥 기본 셸(bash 3.2)**: 긴 답 · 긴 턴에서 종료 훅이 1분 넘게 걸리던 것이 1초 안으로 줄었습니다.

## 올리는 법

```
/plugin marketplace update scv-claude-code
/reload-plugins
```
