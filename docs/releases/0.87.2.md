# 0.87.2

Core 0.87.2 을 싣습니다. 파일(코드 · 문서)을 바꾼 턴은 이제 계획에 기록이 남아야 끝납니다. 계획 안 일이면 진행 한 줄(`plan-link.sh progress`), 계획 밖 일이면 단계 덧붙이기나 보류 후 새 계획, 릴리스 · 동기화만 예외입니다. 기록 줄에는 그 턴의 요청 원문이 붙어 폰에서도 무엇을 했는지 보입니다. 덧붙이거나 진행으로 적으려는 일이 계획의 "하지 않음"과 겹치면 멈추고 먼저 묻고, 보류시킨 계획이 끝났는데 원래 계획으로 돌아오지 않았으면 막습니다. 선택 창 답은 진행 중 계획의 변경 이력에 바로 적힙니다. 끄려면 `scv/scv_settings.json` 의 `SCV_TURN_PLAN_CHECK` 를 `off` 로.

SCV 대시보드(scv-dashboard)가 켜져 있으면, 구현 중인 계획에서 파일을 바꾼 턴은 단계 보고 도구 호출이 있어야 끝납니다 — 대시보드가 실제 진행과 늘 같게. 대시보드가 없으면 계획 파일의 진행 줄로 충분하고, 대시보드도 그 줄로 빠진 단계를 채웁니다(scv-dashboard 0.2.21 이상).

## 올리는 법

```
/plugin marketplace update scv-claude-code
/reload-plugins
```
