# 0.59.1

0.59.0 의 모델별 프롬프팅이 실제 대화에서 켜지지 않던 것을 고칩니다. Core pin 은 `0.59.1` 그대로.

## 무엇이 달라지나

- **이제 실제로 켜집니다.** 0.59.0 은 가이드 원문 폴더의 위치를 잘못 적어, help 가 모델 이름을 받고도 "가이드 없음" 으로
  넘어갔습니다(설치 뒤 실측으로 발견). 이제 지금 답하는 모델의 공식 가이드 원문을 읽고, 요청을 그 기준으로 다시 써 보인 뒤,
  못 찾는 빈 곳만 추천 답과 함께 묻습니다.
- 같은 실수를 막는 검사를 CI 에 넣었습니다 — 색인에 있는 모든 모델 이름이 실제 실행 위치에서 원문을 찾는지.

## 올리는 법

```
/plugin marketplace update scv-claude-code
/reload-plugins
```
