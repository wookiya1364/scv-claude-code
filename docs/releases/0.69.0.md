# 0.69.0

막힌 것이 없으면 '다음?' 창으로 멈추지 않고, 지난 세션을 돌아보며 더 좋은 프롬프트 쓰는 법을 알려 줍니다. Core pin 은 `0.69.0`.

## 무엇이 달라지나

- **다음 일은 묻지 말고 계속**: 막힌 것도 사용자가 정할 것도 없으면, 배경 작업 알림 뒤나 한 단계가 끝난 뒤 '다음으로 무엇을 할까요?'
  선택 창을 띄우지 않고 이어서 일합니다. 진짜 결정(사용자만 정할 수 있는 것 · 되돌리기 어려운 일)은 그대로 묻습니다.
- **드림 — 프롬프트 코치(`/scv:dreams`, 새 명령 · 16번째)**: 이 프로젝트의 지난 세션 기록과 보관된 계획을 읽기만 해서, 계획 하나를
  보관까지 끌고 가는 데 사람 요청이 몇 번 들었는지와 처음 요청을 어떻게 쓰면 더 적게 들지를 보고서로 냅니다(`scv/dreams/` 에만 씀).
  직접 부르거나, 대화 비움 · 압축 직후와 날짜가 바뀐 첫 요청 때 배경으로 돌고, 다음 요청 답 맨 위에 한 줄 요약이 한 번 붙습니다.
  개선점의 조언은 이 래퍼의 판정자(Sonnet, `scripts/show-real-judge.sh`)가 가린 발췌만 보고 씁니다. 끄기: `SCV_DREAMS=off`.
- 보고서 · 요약 · 판정자 입력에는 경로 · 메일 · 비밀값 · 세션 id 가 들어가지 않습니다.
