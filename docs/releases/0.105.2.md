# 0.105.2

SCV 대시보드가 보낸 글을 자동으로 온 글로 알아봅니다. Core 는 0.105.1 그대로입니다.

**대화를 비운 직후 할 일 목록이 더 빨리 다시 뜹니다.** SCV 대시보드(scv-dashboard 0.7.0)는 대화를 자동으로 비운 뒤 `<scv-dashboard>` 로 감싼 글 한 줄을 보내고, 그 턴에서 Claude 가 비우기 전 할 일 목록을 다시 띄웁니다. 지금까지는 이 글이 사람이 친 글로 처리되어 도움말 호출과 요청 등록이 붙었고, 목록이 약 10초 뒤에 떴습니다. 이제 일이 끝났다는 알림과 같은 길로 가서, 턴 시작 검사가 짧고 도움말을 요구하지 않습니다.

## 알아 둘 것

- 업데이트는 `/scv:update` 한 번입니다. 새 판은 새 세션부터 쓰입니다(열려 있는 터미널 세션은 `/reload-plugins`).
- 바뀐 것은 자동 입력 태그 목록의 낱말 하나(`scv-dashboard`)입니다. 사람이 쓴 글이 함께 있으면 지금처럼 사람 턴으로 다룹니다.
- 턴 시작 검사 시간은 임시 복사본에서 세 번씩 측정했습니다: 사람이 친 글 3.0 ~ 3.2초, 자동 글 1.26 ~ 1.29초. 목록이 뜨기까지는 약 5초로 예상합니다(추정). 실제로 비운 직후의 시간은 아직 측정하지 못했습니다.
- 대시보드가 0.7.0 보다 옛 판이면 달라지는 것이 없습니다.
