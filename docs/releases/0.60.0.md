# 0.60.0

모델이 가이드 원문을 실제로 읽었는지, 다시 쓴 요청을 답에 보였는지를 결과로 확인합니다. Core pin 은 `0.60.0`.

## 무엇이 달라지나

- **원문을 안 읽고 넘어가면 다음 턴에 경고가 뜹니다.** 0.59.1 실측에서 help 가 가이드 원문을 알렸는데도 모델이 원문을 열지 않고
  요청을 다시 쓴 일이 있었습니다. 이제 help 가 읽음 표시 명령을 그대로 건네고, 턴이 끝날 때 표시가 없으면 다음 턴 맨 앞에 경고
  한 줄이 실리고 help 가 원문을 다시 읽게 합니다.
- **다시 쓴 요청을 대화 기록에만 남기고 답에 안 보이면 경고가 뜹니다.** 답에 인용 블록(`>`)으로 보여야 합니다. 도구를 부르기 전
  첫 메시지에 보인 것도 인정합니다.
- 답을 막거나 고치지는 않습니다 — 경고만. 한계: 읽음 표시만 하고 실제로 안 읽는 경우는 잡지 못합니다.

## 올리는 법

```
/plugin marketplace update scv-claude-code
/reload-plugins
```
