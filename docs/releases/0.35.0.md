# 0.35.0

Core 0.35.0 동기화.

## 첨부는 실행 기록을 따른다

테스트 러너가 결과 폴더 이름을 잘라도(실측: Playwright 폴더명 절단으로 증적 0건)
PR/보고 증적이 이 계획 소속으로 붙습니다. SCV 가 테스트를 돌린 실행이 만든 파일
목록을 기록(run manifest)하고, 첨부는 기록 → 이름 매칭(폴백) → 0건이면 한 줄
알림 순서로 동작합니다. 같은 브랜치에 열린 PR 이 있으면 새로 만들지 않고
갱신합니다(PR updated).

## 일반 대화에도 SCV 가 끼어듭니다 — SCV_ALWAYS_ON (기본 on)

명령을 치지 않아도 매 메시지가 SCV help 라우팅(Mode A/B/B' 판정)을 거칩니다.
끄기: scv/scv_settings.json 에 SCV_ALWAYS_ON=off. 진행 중인 SCV 액션은
가로채지 않습니다.
