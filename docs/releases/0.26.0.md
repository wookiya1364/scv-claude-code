# scv-claude-code 0.26.0

Pins SCV Core 0.26.0. The deck is redesigned.

## What changes for you

`/scv:deck` output is dark only now, and the diagrams are readable.

The big one: a diagram used to be squeezed into the 840px text column at 0.483
scale, so its 16px labels rendered at **7.7px**. It now uses the full reading
width and stops shrinking at 900px, scrolling instead. Labels no longer clip.

Colours follow the page instead of whatever palette was pasted into the diagram
source. Your existing `.md` files are untouched — the directive stays in them, so
GitHub renders them exactly as before.

The theme toggle is gone. Screen is dark; **printing** switches to light values,
which is new — the previous PDF was 20 pages of dark slabs on white paper.

The header, section nav and footer no longer scroll away with the text. Chrome
before the first sentence: 268px → 109px.

## Fixed along the way

- **Diagrams were never actually baked into the file.** `static-mermaid.mjs`
  produced nothing on recent Chrome, so every deck shipped a CDN loader and
  reported "offline? CDN blocked?". Offline readers saw no diagram.
- Six buttons rendered in a browser fallback font, because five `font:` shorthands
  were invalid CSS and two more set only a size.

## Note

Regenerate any deck you want the new look on — existing `.deck.html` files are
build output and are not migrated.
