# 0.31.0

Core 0.31.0 — "쉬운 말" 규칙을 답의 모양으로 다시 쓰고, 매 턴 전달하고, 끌 수
있게 했습니다.

## 답이 정해진 모양으로 나옵니다

먼저 1–2문장으로 무엇을 얻는지, 그다음 예시 하나, 사용자가 묻기 전에는 파일
경로·변수명·버전·설정값 같은 코드값 없이, 자세한 건 원할 때. 행동에 필요한
식별자(다음 명령, 만든 파일)는 요약 뒤에 그대로 둡니다. 13개 명령 설명서의
"Plain language first" 절이 전부 이 본문으로 바뀌었고, `/scv:help` 대화 모드는
매 턴 "짧은 답 → 예시 → 질문 하나" 로 진행합니다.

## 명령 없이 대화할 때도 규칙이 보입니다

이 플러그인은 이미 `UserPromptSubmit` 에 SCV 기록 훅을 등록해 두었습니다. 그
훅이 이제 SCV 프로젝트에서 매 턴 답의 모양 요약(5줄)을 stdout 으로 내고, Claude
Code 가 그것을 모델 컨텍스트에 넣습니다 — 그래서 `/scv:*` 명령 밖의 일반
대화에도 규칙이 닿습니다. 기록·비차단은 그대로이고, 요약은 journal 에 쓰이지
않습니다.

## 문장 수도 정할 수 있습니다

"먼저 1–2문장"의 2 는 기본값입니다. `.env` 에 `SCV_PLAIN_MAX_SENTENCES=4` 처럼
적으면 첫 답의 상한이 그 수가 됩니다(양의 정수만, 그 밖은 2). 매 턴 요약도 그
숫자로 바뀌어 전달됩니다. 줄 수가 아니라 문장 수인 이유는, 줄 수는 화면 폭에
따라 달라져 모델이 지키기 어렵기 때문입니다.

## 끌 수 있습니다

`.env` 에 `SCV_PLAIN_LANGUAGE=off` 한 줄이면 훅은 침묵하고 명령 안의 절도
스스로 비켜섭니다. 없거나 `on`, 그 밖의 값은 켜짐입니다. `.env` 는 보통
사람마다 다른 파일이라 팀 안에서도 각자 고를 수 있습니다. `.env.example.scv`
에 기본 on 으로 적혀 있고, 템플릿 `scv/SCV.md` 에 "How SCV talks to you" 절이
생겼으며, 예시 루틴 `plain-language-audit` 이 추가됐습니다. TEMPLATE_VERSION
2.3.0 — 기존 프로젝트는 다음 액션 때 autosync 로 자동 수령합니다.
