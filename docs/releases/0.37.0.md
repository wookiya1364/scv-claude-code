# 0.37.0

Core 0.37.0 동기화.

- **번호식 화면설계서** — 기획서가 그림 위주가 됩니다. 큰 그림에 번호(①②③)와
  문자(ⒶⒷ) 마커가 붙고, 설명은 그림 옆 목록으로 빠집니다.
  - FE: 와이어프레임 + 기능/액션 설명 + 컴포넌트 상태 띠 + 검증 메시지 표
    (한 규칙이 여러 번호에 걸리는 것을 한 행에 표현).
  - BE: 같은 부품을 재사용 — 호출 화면 표(어느 화면의 어느 요소가 부르는가),
    구성도 + 순서도 2장, 테이블 스키마 카드, 실패·응답 표.
  - 마커는 안 쓰면 자동으로 붙습니다(컴포넌트 1,2,3 / 액션 A,B,C).
- **순수함수·파이프라인이 모든 계획의 필수 섹션**이 됐습니다. 단계는 순수하게,
  부수효과는 파이프라인 입구와 출구에만 — 재사용과 A/B 검증이 쉬워집니다.
  빠지면 경고가 뜹니다.
- 새 경고: 그림 0장, 마커 짝 불일치, 한 그림 마커 20개 초과 — 전부 경고만.
- 하위 호환: 마커 없는 기존 화면 목업은 바이트 단위로 동일하게 렌더됩니다.
- Core pin `0.36.0` → `0.37.0`.
