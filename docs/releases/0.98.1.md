# 0.98.1

Core 0.98.1 을 싣습니다.

**고친 것 — 주석 옮기기 안전.** 0.98.0 의 주석 옮기기(기본 켬)가 셸 파일 문법을 깨뜨릴 수 있던 일(큰따옴표 안 `$( )` 속 따옴표를 잘못 읽어 문자열 안 `#` 를 지움), 예시 글에 `@pure` · `종류:` 가 든 함수의 사전 항목이 빠지던 일, 사전 쓰기가 실패해도 지운 코드가 남던 일을 고쳤습니다. 이제 지운 뒤 문법을 검사해 깨지는 파일은 그대로 두고 알리며, 옮기기 전 사전 항목이 하나라도 빠지거나 사전 쓰기가 실패하면 코드와 사전을 옮기기 전 그대로(커밋 안 한 편집 포함) 되돌립니다.

**알아 둘 것.** 0.98.0 으로 이미 옮긴 프로젝트는 다시 옮기지 않습니다. 옮긴 결과를 아직 커밋하지 않았다면 `git diff` 로 셸 파일을 한 번 보고, 이상하면 `git checkout -- .` 로 되돌린 뒤 사전 폴더의 `SOURCE` 를 지우면 다음 사람 턴에 새 방식으로 다시 옮깁니다.
