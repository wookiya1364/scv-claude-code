# 0.73.1

Core 0.73.1 을 싣습니다. SCV 지침끼리 같은 순간에 반대로 시키던 곳을 한쪽으로 정리했습니다 — 모델이 매번 다른 쪽을 어기던 일이 줄어듭니다.

- 답 모양 검사: 맨 위 '이렇게 이해하고 일함' 줄은 첫 문장 개수에서 빼고 그다음 결론 문단을 셉니다. 결론 밑에 붙은 인용 · 표 줄에서 결론이 끝납니다.
- 최상위 규칙: 묶어 묻기 허용(답 없이 채우기만 금지), 스크립트가 다시 만드는 보관 색인 · 기획서 HTML 은 불변 대상 밖, 해로운 · 효과 없는 변경은 '묻지 말라'고 해도 한 번 묻고 고른 대로.
- 보관 검색 끝 제안은 선택 창으로, 짧은 턴은 대화 파일이 없으면 일지 한 줄, 첫 실행 결과 확인은 한 번 묻는 예외, 범위 밖 파일은 묻고서만 고침.
