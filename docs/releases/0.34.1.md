# 0.34.1

> 0.34.0 은 래퍼에 실리지 않았습니다 — Core 0.34.0 의 `settings.sh` 파일 끝 빈 줄 하나에 래퍼 core-sync 의 `git diff --check` 가 걸려 고정 PR 이 만들어지지 않았고, Core 0.34.1(빈 줄 제거 + `test-whitespace.sh` 계약)로 다시 실었습니다. 기능 내용은 0.34.0 과 같습니다.

Core 0.34.1 — 설정 파일이 항상 있고, 무엇을 설정할 수 있는지 파일만 열어도 보입니다.

## 설정 파일을 직접 만들 필요가 없습니다

0.32.0 부터 SCV 설정은 `scv/scv_settings.json` 에 있지만, 그 파일을 만드는 건
사람 몫이었습니다 — 업데이트해도 파일이 안 생기는 프로젝트가 있었고, 옛 `.env`
에 아무것도 없던 팀원은 빈 파일을 받아 어떤 값을 정할 수 있는지 알 수 없었습니다.
이제 어떤 SCV 명령이든 시작될 때 파일이 없으면 만듭니다: 모든 설정 키를 실제
기본값과 함께, 옛 `.env` 에 값이 있으면 그 값으로, 그리고 맨 위의 `_doc` 에 키마다
한 줄 설명과 허용값을 적어서요. 이미 파일이 있으면 새로 생긴 키만 더하고 당신이
정한 값은 건드리지 않습니다. 새 프로젝트(hydrate)도 예시가 아니라 실제 파일을
받습니다.

## 비밀 파일은 안전할 때만

토큰·채널 ID 용 비밀 파일은 git 이 무시한다고 확인될 때만 만듭니다 — 무시 줄이
없으면 `.gitignore` 에 한 줄 더하고 확인합니다. git 이 아닌 폴더에서는 만들지 않고
한 줄로 알립니다.

## .env 알림은 값이 다를 때만

옮겨진 뒤에는 조용합니다. 나중에 `.env` 를 고쳤는데 설정 파일과 달라졌을 때만 한
번 알립니다(SCV 는 설정 파일을 읽습니다).
