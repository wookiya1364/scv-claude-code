# 0.84.0

Core 0.84.0 을 싣습니다. 두 가지가 바뀝니다.

- **다시 쓴 요청에 낱말 목록**: 한국어 설정(`SCV_LANG=korean`)이면 help 가 다시 쓰기 전에 한국어판 STE 목록(항공 정비 설명서용 쉬운 영어 ASD-STE100 규칙을 옮긴 R1–R15 · 허용 동사 · 금지 낱말 · 용어)을 세션마다 한 번 싣고, 다시 쓴 요청이 그 목록을 따릅니다. 실제 요청 20개를 가린 채 비교한 결과, 다시 쓴 요청은 15승 3패였고 길이는 269자에서 157자로 줄었으며, 그 글을 받은 답은 10승 8패였습니다. 끄려면 설정에 `SCV_REWRITE_STE=off`.
- **규칙 문구 두 곳 정리**: 첫 행동 안내에 "할 일 목록 같은 진행 표시 도구는 help 전에 함께 보내도 된다"를 적고, 앱의 마무리 상자가 질문을 허용해도 결정은 선택 창으로 묻는다고 밝혔습니다.

## 올리는 법

```
/plugin marketplace update scv-claude-code
/reload-plugins
```

열려 있던 세션은 다시 시작해야 새 목록이 실립니다.
