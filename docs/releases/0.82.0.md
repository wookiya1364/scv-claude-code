# 0.82.0

Core 0.82.0 을 싣습니다. 도구를 쓴 턴의 끝 보고 끝에 '확인한 것 · 확인 못 한 것 · 제가 대신 정한 것' 세 줄이 붙습니다(기록 · 질문만 한 턴은 '확인 범위' 한 줄). 이번 턴에 실제로 한 일(읽음 · 바꿈 · 실행 · 시험과 결과)을 기계가 모아 그 세 줄과 맞춰 보고, 빠지거나 맞지 않으면 한 번 다시 쓰게 합니다 — 일을 다 끝낸 것처럼 포장하지 못하게 하고, 사람이 근거를 보고 판단하게 하려는 실험입니다. 끄려면 설정에 `SCV_FINISH_REPORT=off`. 언어 교정 문구에는 이제 걸린 줄이 함께 나옵니다.

## 올리는 법

```
/plugin marketplace update scv-claude-code
/reload-plugins
```
