# 0.61.0

새 대화의 첫 턴부터 모델이 가이드 원문을 읽도록 안내합니다. Core pin 은 `0.61.0`.

## 무엇이 달라지나

- **새 대화의 첫 턴부터 모델이 자기 프롬프팅 가이드 원문을 읽도록 안내합니다.** 지금까지는 첫 턴에 원문을 건너뛰고 둘째 턴에
  경고를 받은 뒤에야 읽었습니다(실측). 이제 새 대화 · 압축 · 재개 뒤 첫 턴에, 매 턴 알림 맨 앞쪽에 "답하기 전에 이 원문을 읽고
  이 명령을 실행하라" 가 원문 경로와 함께 실립니다.
- 이미 읽은 뒤의 평소 턴에는 아무것도 더 실리지 않습니다(비용 그대로).
- 예외: 이 프로젝트에서 SCV 를 처음 쓰는 첫 턴, 모델을 바꾼 직후 첫 턴 — 이때는 지금처럼 help 안내와 다음 턴 경고로 바로잡습니다.

## 올리는 법

```
/plugin marketplace update scv-claude-code
/reload-plugins
```
