# 0.99.0

Core 0.99.0 을 싣습니다.

**바뀐 것 — 답 · 중간 보고를 설정 언어로.** 사용자가 SCV 에 정한 언어(`SCV_LANG`)로 답과 도구 사이 중간 보고가 나오게 했습니다. 규칙이 한 줄로 실리는 턴에도 설정 언어 줄이 실리고, 도구 결과 뒤에는 짧은 설정 언어 알림이 붙습니다 — 이번 턴의 마지막 글이 이미 그 언어면 붙지 않습니다. 언어 검사는 한국어 밖으로 넓어져 일본어 · 중국어 설정에서도 다른 언어 줄을 잡습니다. english 설정은 그대로입니다.

**알아 둘 것.** 긴 작업에서 도구마다 짧은 알림 한 줄(약 60바이트)이 붙을 수 있습니다. 끄려면 설정에 `SCV_ANSWER_LINT=off` 를 적습니다(언어 검사 전체가 꺼집니다).

## 올리는 법

```
/plugin marketplace update scv-claude-code
/reload-plugins
```
