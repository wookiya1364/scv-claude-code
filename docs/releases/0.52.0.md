# 0.52.0

계획서가 바뀔 함수를 먼저 말하고, 기획서가 그것을 그림으로 보여줍니다. Core pin 은 `0.52.0`.

## 무엇이 달라지나

- **변경 지도.** 계획 폴더로 만든 기획서에 절 하나가 자동으로 붙습니다. 계획서의 `## 순수함수 · 파이프라인` 표에
  단계마다 상태(추가 · 변경 · 삭제 · 재사용)를 적으면, 그 파이프라인이 상태별 색으로 구분된 머메이드 그림 한 장과
  표 하나로 그려집니다. 삭제로 가는 선은 점선입니다. 상태 칸이 없는 옛 서식도 그대로 읽히고 그때는 `미지정` 이
  되며, 계획서가 삭제를 말하지 않으면 삭제 행은 아예 만들지 않습니다 — 없는 것을 지어내지 않습니다. 한 장짜리
  마크다운 문서에는 이 절을 만들지 않습니다(가져올 계획이 없으므로).
- **화면과 함수가 이어집니다.** 화면 설계의 번호 붙은 항목이 파이프라인 단계를 가리키면 그 상태까지 함께 보입니다.
  화면을 보면 그 컴포넌트를 움직이는 함수와, 그 함수가 이번에 새로 생기는지가 한눈에 읽힙니다.
- **Graft 는 선택입니다.** 있으면 선언한 단계가 실제 코드에 있는지 대조해 `일치` · `이미 있음` · `근거없음` 으로
  표시합니다. 대조는 표시일 뿐 계획서의 선언을 고치지 않습니다. 없으면 대조 열이 전부 `근거없음` 이 되고 설치
  명령 한 줄을 안내하며, 그림과 표는 그대로 나옵니다. SCV 는 여전히 Graft 를 설치·초기화·빌드·훅 하지 않습니다.
- **벽시계 단언 제거.** 검사 셋이 "이 일이 N밀리초 안에 끝나야 한다" 를 단언하고 있었습니다. 기계가 바쁘면 코드와
  무관하게 무너졌고, 그 검사들을 공유하는 보관 계획 25건이 한꺼번에 붉었습니다. 단언을 전부 걷어냈습니다. 걸린
  시간은 출력에 남겨 사람이 보게 하고, 초록·붉음을 가르지 않습니다. 타임아웃을 보는 검사는 "빈 출력 + exit 0"
  이라는 관찰 가능한 결과만 봅니다.
- **deck 안내문 중복 수정.** 큰 그림이 없을 때 주던 선택지 (1)번과 (2)번이 같은 명령이었습니다 — 0.51.0 에서
  graphify 를 걷어내며 남은 자국입니다. 이제 셋이 서로 다릅니다.
