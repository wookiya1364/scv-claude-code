# 0.83.0

Core 0.83.0 을 싣습니다. 두 가지가 바뀝니다.

- **같은 답이 두 번 보이지 않게**: 종료 검사(확인 범위 · 언어 · 다시 쓴 요청 · 선택지 등)가 답을 막고 다시 쓰게 하던 것을 그만두고, 어긋난 점을 다음 턴 첫 안내(`[SCV 직전 답] …`)로 넘깁니다. 실제 세션 186턴 중 78턴에서 막힘이 생겨 다시 쓴 답이 인용 · 세 줄을 되풀이했습니다. 예전처럼 막으려면 설정에 `SCV_STOP_MODE=block`. 제목형 확인 범위(`**확인한 것**` 아래 목록)를 빠진 줄로 보던 오탐도 고쳤습니다.
- **가이드 다시 읽기 양 줄이기**: 압축 · 세션 시작마다 읽는 공통 프롬프팅 가이드를 요구 항목 인용이 든 구역만 원문 그대로 뽑은 발췌본으로 바꿉니다(65,354B → 8,159B, 한 번에 약 94KB → 37KB). 원문 사본은 그대로 두고 `prompting/check.sh` 가 발췌본이 원문에서 기계적으로 뽑힌 것인지 확인합니다.

## 올리는 법

```
/plugin marketplace update scv-claude-code
/reload-plugins
```

열려 있던 세션은 다시 시작해야 새 종료 방식이 적용됩니다.
