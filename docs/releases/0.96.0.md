# 0.96.0

Core 0.96.0 을 싣습니다.

**바꾼 것 — 매 턴 규칙 글은 한 번만.** 언어 · 확인 범위 · 답 모양 · 선택 · 실물 보여 주기 안내를 첫 턴 · 대화 요약 뒤 · 규약을 다시 읽는 턴 · 경고가 남은 턴에만 전부 싣고, 그 밖의 턴은 한 줄로 줄입니다. 실제 세션 기록으로 다시 계산하면 사람 턴마다 붙는 글이 약 60% 줄어듭니다. 예전처럼 매 턴 싣으려면 `SCV_RULES_ONCE=off`.

**바꾼 것 — 숫자 길이 상한 없음.** 결론 줄 · 줄글의 문장 수와 불릿 길이를 세지 않습니다. 답 모양(굵은 주제 → 결론 → 불릿) · 개조식 끝맺음 · 다시 쓴 요청 인용은 그대로입니다.

**그대로인 것.** 답 모양 검사의 나머지 항목, 끝 보고 세 줄, 선택 창으로 묻기.

/plugin marketplace update scv-claude-code
