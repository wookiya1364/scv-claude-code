# 0.45.0

Core 0.45.0 동기화.

## SCV 명령이 세션 모델을 바꾸지 않습니다

지금까지 SCV 명령마다 "이 명령은 Opus 로, 저 명령은 Haiku 로" 가 정해져 있어서, 명령이
도는 동안 세션 모델이 바뀌었습니다. help 가 매 턴 불리는 0.43.0 이후로는 **Fable 세션에서도
사실상 매 턴 Opus 가 답하고 있었습니다.** 고르신 모델이 무시된 셈입니다.

## 무엇이 달라지나

- **기본이 세션 모델입니다.** 명령 파일에서 모델 지정을 전부 걷어냈습니다. 플러그인을
  갱신하면 아무 명령도 모델을 바꾸지 않습니다 — 따로 할 일 없습니다.
- **비용을 아끼려면 켤 수 있습니다.** `/scv:set-models` 에서 가벼운 명령은 Haiku, 무거운
  명령은 Opus 로 도는 매핑을 고를 수 있습니다. 첫 선택지는 "세션 모델 그대로" 입니다.
- **선택이 이제 실제로 저장됩니다.** 전에는 저장 단계가 사라진 스크립트를 불러 적용만
  되고 저장은 실패했습니다. 이제 설정 파일에 남고, 플러그인 갱신 뒤 `/scv:sync` 한 번이면
  매핑이 돌아옵니다. 매핑을 켜지 않은 분은 sync 도 필요 없습니다.

- Core pin `0.44.0` → `0.45.0`.
