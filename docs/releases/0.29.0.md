# 0.29.0

Core 0.29.0 — effort governor 를 싣습니다.

## 작업 무게에 맞춰 알아서 돕니다

이제 `/scv:work` / `/scv:codegen` 이 구현 전에 계획의 실행 밴드를 판정합니다
(백테스트 13/14 를 통과한 3규칙 — 선언 > parallel_groups > 래퍼 후속 > standard).
세션의 `/effort` 설정은 건드리지 않습니다 — 조절되는 것은 실행 방식이고, 그
지배항은 다중 에이전트 팬아웃입니다. standard 계획은 팬아웃을 띄우지 않으므로,
ultracode 세션에서도 가벼운 계획은 조용히 싸게 돕니다.

이 호스트의 밴드×단계 매핑(README 의 표): 기계 단계 low · 종합 medium · 구현
high/xhigh · 검증 high/max/팬아웃. 승급은 위로만(같은 단계 적색 2회 또는 반박
반복), 검증 중 강등 없음. `.env` 의 `SCV_EFFORT_MODE=auto|ask|off` — off 는
이전 동작과 완전히 동일합니다. 계획 frontmatter 의 `effort_class:` 선언이나
대화 한마디로 언제든 뒤집을 수 있습니다.
