# SCV Claude Code 0.23.0

Core `0.23.0` 을 pin 한다. 어댑터 코드 변경은 없다 — 이번 웨이브는 전부 Core 쪽이다.

## Core 0.23.0 이 가져오는 것

### 결정 로그가 실제로 작동한다

`scv/DECISIONS.md` 는 v0.22.0 에 도입됐지만 기록이 도달하는 경로가 없어 엔트리가
쌓이지 않았다. `/scv:work` 가 `--archive` 로만 호출될 때 결정 로그 단계를 건너뛰던
것을 고쳤고, 아카이브 엔트리에 `path delta:` 한 줄이 생겼다 — 계획이 제시한 경로와
실제로 간 경로가 어떻게 달랐는지, 그리고 왜인지.

계획대로 갔다면 `as planned` 한 단어로 끝난다.

### 구현 원칙 4종

`/scv:work` 와 `/scv:codegen` 이 구현할 때 기본으로 지키는 것 — 기존 코드를 먼저
찾아 재활용, 현재 요구를 충족하는 가장 단순한 구현, 관심사 하나당 컴포넌트 하나,
되돌리기 비싼 결정은 장기 관점. PLAN 의 `Guardrails` 가 항상 우선한다.

### 쉬운 말 먼저

계획 설명과 진행 보고가 길고 어려워지는 것을 막는 규칙이 프로토콜 13개에 들어갔다.
짧게 먼저 말하고, 더 필요하면 그때 자세히.

### 계획서 린트가 실제 계획서를 통과시킨다

`check-frontmatter` 가 표준 문서 스키마를 promote 계획서에도 적용해, 문서화된
템플릿으로 쓴 계획서가 전부 거부되고 있었다. 계획서는 계획서 스키마로 검사한다.

### 릴리스 전파가 조용히 실패하지 않는다

Core 릴리스가 래퍼에 알림을 보내지 못하면 이제 릴리스 run 이 실패로 표시된다.
예전에는 알림이 건너뛰어져도 초록불이었다. 주 1회 토큰 헬스체크도 추가됐다.
