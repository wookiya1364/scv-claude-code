# 0.87.3

Core 0.87.3 을 싣습니다. 턴 끝 계획 검사가 이제 이 세션이 실제로 고친 파일만 셉니다. 전에는 파일을 읽기만 한 폴더도 "건드린 폴더"로 치고, 그 폴더에서 다른 세션이 고친 파일까지 이 세션 탓으로 막았습니다(같은 폴더에서 두 세션을 동시에 쓸 때). 이제 편집 도구는 적힌 파일만, 셸 명령은 명령 앞뒤 모습의 차이만 이 세션 몫으로 셉니다. 남는 한계: 셸 명령과 다음 도구 사이에 다른 세션이 같은 폴더를 고치면 그 파일은 섞일 수 있습니다.

## 올리는 법

```
/plugin marketplace update scv-claude-code
/reload-plugins
```
