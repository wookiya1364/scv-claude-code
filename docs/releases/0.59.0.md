# 0.59.0

모델을 바꿔도 그 모델에 맞춘 프롬프트로 일합니다. Core pin 은 `0.59.1`.

## 무엇이 달라지나

- **help 가 지금 답하는 모델의 공식 프롬프팅 가이드 원문을 읽습니다.** 모델마다 공식 가이드가 따로 있습니다(Fable 5.1 ·
  Fable 5 · Opus 5.5 · Opus 5 · Opus 4.8 · Sonnet 5 + 공통 모범 사례). 플러그인이 그 원문을 오프라인 사본으로 싣고, 모델이
  바뀌거나 새 대화 · 압축 · /clear · 재개 뒤 처음이면 help 가 원문을 한 번 읽게 합니다. 인터넷 없이 됩니다.
- **요청을 그 가이드 기준으로 다시 써서 보여 준 뒤 그것으로 일합니다.** 가이드가 그 모델에 권하는 요소(목표 · 끝 조건 · 범위 ·
  멈출 조건 · 피할 것)를 대화 · 저장소 · 계획에서 먼저 찾아 채우고, 못 찾는 것 중 결과를 가장 크게 바꾸는 하나만 추천 답과 함께
  묻습니다(소크라테스식). 사용자의 원래 문장은 그대로 남습니다.
- **저널의 답 기록에 답한 모델이 붙고, 계기판이 모델별 답 수를 셉니다.**
- 설정: `SCV_MODEL_PROMPTING`(on · 기본 / off), `SCV_MODEL_PROMPTING_MAX_AGE_DAYS`(90 — 원문 사본이 이보다 오래되면 갱신 명령을
  한 줄 알림). 원문 갱신: `bash prompting/refresh.sh` (플러그인 폴더에서).

## 올리는 법

```
/plugin marketplace update scv-claude-code
/reload-plugins
```
