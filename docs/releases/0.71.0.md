# 0.71.0

설치된 SCV 를 개발 · 스테이징 · 운영 채널 사이에서 바꿔 끼우는 `/scv:channel` 이 생겼습니다. 운영 릴리스를 기다리지 않고 새 작업을 먼저 써 보고, 다시 운영으로 돌아올 수 있습니다.

- `/scv:channel` — 지금 채널을 보여 주고, 고른 채널로 바꿉니다(지우기 → 그 채널 브랜치로 다시 넣기 → 설치). 채널 브랜치가 없으면 아무것도 바꾸지 않고, 중간에 실패하면 원래 채널로 되돌립니다.
- 채널 브랜치: 개발 = `channel/dev`(래퍼 develop + 코어 develop), 스테이징 = `channel/stage`. 코어 develop · stage 가 바뀔 때마다 자동으로 다시 만들어집니다. 운영(main)과 릴리스 절차는 그대로입니다.
- 채널 버전은 `0.71.1-dev.<커밋>` 처럼 채널과 커밋이 보여, 지금 무엇이 도는지 알 수 있습니다.

## 올리는 법

```
/plugin marketplace update scv-claude-code
/reload-plugins
```
