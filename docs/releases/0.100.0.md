# 0.100.0

Core 0.100.0 을 싣습니다.

**새로 생긴 것 — 기어와 톱니.** 되풀이되는 작업을 프로젝트 `scv/gears/` 안의 재사용 단위로 만듭니다. 톱니는 순수함수처럼 한 가지 일만 하는 아주 작은 sh(`scv/gears/teeth/`), 기어는 맨 위 `flow:` 줄로 톱니를 합성함수처럼 잇는 스킬(`scv/gears/<이름>/GEAR.md`)입니다. 기어를 돌리면 톱니는 스크립트가 직접 돌리고, 판단이 필요한 자리(`@`)에서만 그 기어의 글과 앞 단계 결과를 Claude 에게 넘깁니다 — 스킬 글을 옮기는 것만으로는 토큰이 줄지 않고, 정해진 흐름을 sh 로 내린 만큼 줍니다. `.claude` 폴더에는 아무것도 쓰지 않습니다.

**새로 생긴 것 — `/scv:gear`.** 목록 · 만들기 · 검사 · 실행을 합니다. "이 작업을 기어로 만들어 줘"라고 말해도 됩니다. 검사는 순수 톱니를 사전의 예시로 실제로 돌려 맞춰 봅니다.

**밖으로 나가는 톱니는 확인 뒤에만.** push · 네트워크 · 삭제를 하는 톱니는 그 앞에서 멈추고 선택 창으로 묻습니다. "실행"을 고른 뒤에만 돕니다.

**고친 것.** 선택 창 답이 질문과 관계없는 진행 중 계획에 적히던 일, 그 글이 한글 글자 중간에서 잘려 깨지던 일.

**알아 둘 것.** 비슷한 요청이 되풀이될 때 "기어로 만들까요?"를 먼저 묻는 기능은 다음 릴리스 예정입니다. 스킬 설명 글의 합계가 한도에 닿아 `/scv:promote` · `/scv:install-deps` 설명에서 낡은 문장을 하나씩 뺐습니다.
