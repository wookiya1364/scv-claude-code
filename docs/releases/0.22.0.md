# SCV Claude Code 0.22.0

Released: 2026-08-07

## Core 0.22.0 sync (scv-simplification epic)

- The pinned SCV Core moves to `0.22.0` — Template **2.0.0** — via
  `vendor/scv-core/VERSION` and `core.lock`. This wrapper release registers
  the two adapter-owned surfaces the sync requires: the 15th action
  `/scv:routine` and the journal hook seam (`hooks/hooks.json`).

## BREAKING: seven standard docs retired

- Template 2.0.0 removes the seven standard docs (INTAKE / DOMAIN /
  RALPH_PROMPT / AGENTS / ARCHITECTURE / DESIGN / TESTING). On existing
  projects, `/scv:sync` deletes them in a version-gated one-time migration:
  it fires only for pre-2.x template stamps, skips symlinked `scv/` trees,
  and git history is the recovery path for anything you still need.
- The hydration witness moves from `scv/INTAKE.md` to `scv/PROMOTE.md`.

## Guardrails-first PLAN grammar

- `PLAN.md` now leads with guardrails: what must not change comes before what
  will, so plans state their blast radius up front and reviews start from the
  constraints instead of reconstructing them.

## Per-author team journal + DECISIONS/TODO

- Free conversation is captured into a committed per-author team journal
  (`scv/journal/<YYYYMMDD>-<author>.md`) alongside `scv/DECISIONS.md` and
  `scv/TODO.md`, with built-in redaction — secret-shaped values (e.g.
  `password=hunter2`) are stored as `[REDACTED]` and the originals never
  touch disk.

## NEW: `/scv:routine` (15th action)

- `/scv:routine` is registered in this release: routine catalog
  (`--list`), lint, and run protocol projected from Core like the other 14
  actions. Scheduling stays host-owned — the wrapper ships no
  crontab/systemctl/launchctl registration code, guidance text only.

## Guidance markers

- Protocol output is wrapped in `SCV:GUIDANCE` markers, and
  `SCV_GUIDANCE=minimal` trims the guidance for teams that want terse
  actions.

## Hooks seam

- The plugin's `hooks/hooks.json` registers `UserPromptSubmit` →
  `on-user-prompt.sh` and `Stop` → `on-stop.sh` (vendored Core templates,
  `SCV_CORE_ROOT` exported). Hooks are non-blocking — invalid JSON, a
  missing transcript, or an un-hydrated cwd exit 0 with no writes — and the
  journal append honors the redaction contract above.
- Mixed-version caution: update the Claude Code and Codex wrappers together
  on shared projects; a pre-0.22.0 wrapper still expects the retired docs
  and the old hydration witness.
