# 0.94.1

`/scv:update` 가 직접 올립니다 — 터미널 세션에서도 Claude 앱에서도, SCV 와 설치된 모드를 한 번에. Core 는 0.94.0 그대로입니다.

**바꾼 것 — `/scv:update`.**
- 새 버전이 있으면 묻지 않고 올리고, 앞뒤 버전을 알려 줍니다. 지금까지는 슬래시 명령 두 줄을 안내만 했는데, 그 명령은 Claude 앱에 입력하면 플러그인 화면만 뜨고 올라가지 않았습니다.
- 설치된 SCV 모드(예: `scv-dashboard`)도 이어서 올립니다. SCV 가 이미 최신이어도 모드는 올립니다. 두 결과는 따로 알려 줍니다.
- 최신 버전을 `git` 으로 읽습니다. `gh` 가 없는 컴퓨터에서도 "확인 불가"가 아니라 버전이 나옵니다.
- 설치 범위(계정 전체 · 이 프로젝트)가 여럿이면 범위마다 올립니다.
- "최신인지만 알려 줘"처럼 확인만 요청하면 아무것도 바꾸지 않습니다.
- 개발 · 스테이징 채널 설치본은 올리지 않고 `/scv:channel` 을 안내합니다.

**바꾼 것 — `/scv:mods`.**
- 같은 모드가 두 범위에 깔려 있으면 범위마다 올립니다. 지금까지는 한쪽만 올랐습니다. 한 범위에만 깔려 있으면 지금과 같습니다.

**그대로인 것.** 올린 것은 새 세션을 열어야 적용됩니다(터미널 세션은 `/reload-plugins` 로도 됩니다). 프로젝트 파일은 바꾸지 않습니다.

## 올리는 법

이번 한 번은 지금까지의 방법으로 올립니다. 그다음부터는 `/scv:update` 한 번이면 됩니다.

터미널 세션:

```
/plugin marketplace update scv-claude-code
/reload-plugins
```

Claude 앱(셸에서):

```
claude plugin marketplace update scv-claude-code
claude plugin update scv@scv-claude-code
```

그다음 새 세션을 엽니다.
