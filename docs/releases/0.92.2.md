# 0.92.2

Core 0.92.2 을 싣습니다.

**고친 것.**
- 계획에 기록을 남겼는데도 턴이 "계획 기록이 없다 · 진행 중 계획이 없다"로 막히던 것. 기록 명령을 경로를 변수에 담아 돌리거나, 다른 명령 뒤에 이어서 돌리거나, 둘째 줄에서 돌리면 턴 끝 검사가 그것을 기록으로 알아보지 못했습니다. 이제 기록 명령이 기록을 실제로 남긴 뒤 스스로 표시를 더합니다. 손으로 쓴 가짜 줄과 실패한 기록 명령은 지금처럼 막힙니다.
- 파일을 붙여 보낸 요청의 경로가 계획 기록에 그대로 적히던 것. 기록에 붙는 요청 글에서 첨부 파일의 경로를 "[첨부]"로 바꿉니다(메일 주소나 상대 경로는 그대로).

**코어 쪽 정리.** 가장 긴 시험을 네 파일로 나누고 조각 시간표를 실제 릴리스의 시간으로 다시 적었습니다(릴리스 검증의 여섯 조각이 더 고르게 나뉩니다). 붐빌 때 흔들리던 시험 둘을 고쳤습니다.
