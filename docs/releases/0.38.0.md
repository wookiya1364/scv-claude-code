# 0.38.0

Core 0.38.0 동기화.

- **기획서는 그림만** — 계획 폴더로 기획서를 만들면 이제 **그림 문서만** 본문에
  들어갑니다. 0.37.0 의 번호식 화면설계서가 스무 절 중 한두 절뿐이고 나머지는
  예전 방식 글 덩어리로 딸려 나오던 문제를 없앱니다 (실측: 22절 → 4절).
- **잃는 정보는 없습니다.** 계획서와 테스트 문서는 옆에 접힌 원문 패널에 탭으로
  그대로 따라다닙니다.
- **셋 다 보려면 `--full`** — 예전 전체 결합이 그대로 나옵니다. 그 결과는 이
  변경 전과 **바이트 단위로 동일**합니다.
- **그림 문서가 없으면 만들지 않습니다.** 사유 한 줄을 내고 정상 종료합니다
  (오류가 아닙니다) — 그 내용은 이미 계획서·테스트 문서에 있기 때문입니다.
- **빠진 절 경고는 그대로 정확합니다.** 계획 문서를 본문에서 빼도 비목표·
  성공지표·인수기준·예외처리·순수함수 경고가 거짓으로 뜨지 않습니다.
- Core pin `0.37.0` → `0.38.0`.
