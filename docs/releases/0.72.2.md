# 0.72.2

Core 0.72.2 를 싣습니다. 플러그인 안의 중복 deck 엔진 사본을 없앴습니다 — `/scv:deck` 결과는 그대로입니다.

- 플러그인 맨 위의 `DeckUI/` 사본을 지웠습니다. deck 은 코어 사본 안의 엔진(`vendor/scv-core/core/DeckUI`)을 래퍼 설정 `SCV_DECKUI_DIR` 로 찾습니다. 같은 계획에서 바꾸기 전과 바이트까지 같은 deck HTML 이 나오는 것을 확인했고, 슬라이드도 만들어집니다.
- 처음 deck 을 만들 때 엔진 캐시를 한 번 다시 깔 수 있습니다.
- 고친 버그: deck 생성기가 Graft 어댑터를 못 찾던 문제. Graft 가 준비된 저장소에서는 deck 문서에 변경 지도가 붙습니다(의도된 변화).

## 올리는 법

```
/plugin marketplace update scv-claude-code
/reload-plugins
```
