# 0.69.1

이제 안내가 "그냥 말하면 된다"에 맞춰졌습니다 — 새로 설치해도 설정 단계에서 멈추지 않습니다. Core pin 은 `0.69.1`.

## 무엇이 달라지나

- **진단이 알림 설정에서 멈추지 않음**: 알림(Slack · Discord) 설정이 없으면 추천 다음 행동이 늘 "설정 예시를 설정 파일 위에
  복사"였습니다 — 언어만 든 설정 파일을 덮어쓰는 명령입니다. 이제 추천은 상태대로 고르고, 알림은 맨 아래 선택 줄로만 나옵니다.
- **준비됨 · 설치 안내의 첫 입구가 "그냥 말하기"**: 매 요청이 알아서 SCV 로 가므로(`SCV_ALWAYS_ON`, 기본 켬) `/scv:help "…"` 를
  직접 칠 필요가 없다고 안내합니다. 그 설정을 끈 프로젝트만 예전처럼 명령을 안내합니다.
- **문서 · 메시지 6곳**: 계획 규약, raw 안내, "다듬을 것 없음" 메시지, 대화 멈춤 · 이어가기 안내, help 규약의 대화 모드 설명이
  같은 기준으로 바뀌었습니다. 테스트(`test-help-guidance.sh`, 17개 검사)로 고정했습니다.
