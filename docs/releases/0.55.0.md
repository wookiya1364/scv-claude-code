# 0.55.0

Graft 가 없으면 무엇이 좋아지는지 먼저 알리고, 규칙 헌법이 남긴 충돌들을 닫습니다. Core pin 은 `0.55.0`.

## 무엇이 달라지나

- **Graft 안내.** Graft 가 설치되지 않았고 저장소에 Graft 가 인덱싱하는 언어의 파일이 있으면, 계획(promote)과
  구현(work·codegen) 헤더에 한 줄이 실립니다 — 있으면 무엇이 좋아지는지(관련 코드 후보·변경 영향 범위)와 설치 한 줄
  명령. 그래프만 없으면 `graft init` 안내. 묻지도 막지도 않고, 셸 파일만 있는 프로젝트에서는 침묵합니다. 문구와
  설치 명령은 코어 한 곳에만 있습니다.
- **규칙 충돌 후속.** help 는 새 요청이 미완료 대화들과 주제가 명백히 다르면 묻지 않고 새 대화를 열고 한 줄로 알립니다.
  상시 문구(쉬운 말)에는 "실행 중 액션의 단계 규칙이 이 문구보다 먼저다" 가 참조형으로 적혔습니다. 기록 의무는
  `core/contracts/recording.md` 한 곳에 있고 모든 Core 액션 프로토콜이 짧은 절 하나로 가리킵니다. 동기화의 동의
  기준은 한 문장입니다 — 삭제가 없는 갱신은 자동, 삭제가 있으면 미리보기와 승인.
- **누출 차단은 함수 하나.** 회귀 실행기와 PR 도우미의 증거 재실행이 같은 함수로 설정 파일 값을 자식에 넘기지
  않습니다. 사용자가 직접 export 한 값은 그대로 흐릅니다.
- 이 래퍼에는 이슈 하나가 열렸습니다: 업데이트 스킬의 "버전 보고" 문구를 코어 해소 순서 참조형으로 정리하는 일.
  출력은 그대로입니다.

## 올리는 법

```
/plugin marketplace update scv-claude-code
/reload-plugins
```
