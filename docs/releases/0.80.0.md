# 0.80.0

Core 0.80.0 을 싣습니다. 사람이 쓴 턴에서 SCV help 를 부르기 전에는 다른 도구(요청 등록 포함)를 쓸 수 없습니다 — 첫 도구에서 막고, 도구 없이 글만 쓴 턴은 끝낼 때 한 번 막습니다. 긴 작업 세션에서 help 를 건너뛰어 대화 기록이 멈추던 일을 막습니다. 매 턴 지시도 'help 를 부른 뒤 등록' 한 순서로 바꿨습니다.

## 올리는 법

```
/plugin marketplace update scv-claude-code
/reload-plugins
```

새 훅은 플러그인을 다시 불러온 뒤 시작한 세션부터 적용됩니다.
