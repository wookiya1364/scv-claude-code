# 0.93.0

Core 0.93.0 을 싣습니다.

**더한 것 — 마무리 보고.**
- 계획 폴더에 세 번째 파일 `WRAPUP.md` 가 생깁니다. 일곱 묶음 16칸입니다: 문제 · 관찰 · 가설 · 실험 · 원인 · 해결과 검증 · 배운 것.
- 계획을 세울 때 아는 칸(적어도 문제)을 채우고, 일이 끝난 뒤 나머지를 채웁니다.
- 빈 칸이 있으면 보관되지 않습니다. 보관 명령이 어느 칸이 비었는지 이름을 댑니다.
- 보관된 뒤 끝 답에서 마무리 보고를 한 번 보여 줍니다.
- 고장을 고치는 계획이 아니면(새 기능) 가운데 넷 — 관찰 · 가설 · 실험 · 원인 — 은 묶음마다 "해당 없음 — 이유" 한 줄로 건너뜁니다. 문제 · 해결과 검증 · 배운 것은 모든 계획이 채웁니다.
- 이 버전 전에 세운 계획은 그대로 보관됩니다(알림 한 줄만 나옵니다).

**바꾼 것 — 계획 없는 변경은 없습니다.**
- 5줄 이하 변경을 계획 없이 하던 길(빠른 길)을 없앴습니다. 문서는 그 길을 허용하는데 턴 끝 검사는 이미 막고 있어 둘이 어긋나 있었습니다.
- 크기와 상관없이 모든 변경은 계획을 거칩니다. 예외는 릴리스와 동기화 둘뿐입니다(지금까지와 같습니다).
- 줄 수 설정 `SCV_FAST_PATH_LINE_THRESHOLD` 는 없어졌습니다. 설정 파일에 남아 있어도 오류는 나지 않습니다.

**고친 것.** 재는 명령이 잠깐 바쁜 컴퓨터에서 "재지 못함"을 내던 것 — 그런 함수만 최대 두 번 더 잽니다. 규칙과 한도는 그대로입니다.
