# 0.46.1

릴리스 도구 정리. 플러그인 동작은 0.46.0 과 같습니다.

## 버전 도우미가 더는 오류로 끝나지 않습니다

릴리스마다 버전을 올리는 도우미가 README 세 개에서 "릴리스는 ⋯" 문장을 찾아 고치려
했습니다. 그 문장은 진작 배지(맨 위에서 GitHub 최신 릴리스를 읽어 오는 것)로 바뀌어
사라졌고, 못 찾은 도우미는 매번 오류로 끝났습니다. 버전 파일 셋은 그 전에 이미
갱신되므로 릴리스 결과에는 문제가 없었지만, 터미널을 보는 사람만 알아챌 수 있었습니다.

- 죽은 README 갱신 부분을 걷어냈습니다. 도우미는 이제 버전이 실제로 적히는 세 곳만
  씁니다.
- 계약 검사가 그 도우미를 **직접 돌립니다.** 지금 버전을 다시 적용해 정상 종료와
  "아무 것도 바뀌지 않음" 을 확인하므로, 같은 일이 조용히 되살아나지 못합니다.
- 릴리스 안내 문서에서 "README 세 개까지 고친다" 는 설명을 사실대로 바꿨습니다.

Core pin 은 `0.46.0` 그대로입니다.
