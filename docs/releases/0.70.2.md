# 0.70.2

계획서 양식이 단계마다 '하는 일'을 적고, 단계 줄을 파이프라인 표와 잇게 바뀌었습니다. Core pin 은 `0.70.2`.

## 무엇이 달라지나

- 새로 만드는 계획서의 `순수함수 · 파이프라인` 표에 **'하는 일'** 칸(한 줄, 쉬운 말)이 생깁니다.
- `Suggested path` 줄 끝에 그 줄이 만드는 단계를 `` — `단계`, `단계` `` 로 적습니다(표의 단계 칸과 글자 그대로).
- 그래서 scv-dashboard 모드의 단계 흐름이 단계마다 '하는 일'을 보여 줍니다. 전에는 연결이 없어 "계획서 파이프라인 표에서 이 단계가 하는 일을 찾지 못했습니다"가 떴습니다.

## 이미 쓴 계획서

그대로 읽힙니다. 대시보드에 '하는 일'이 보이게 하려면 그 계획서의 표에 '하는 일' 칸을, 단계 줄 끝에 연결을 더하면 됩니다.

## 올리는 법

```
/plugin marketplace update scv-claude-code
/reload-plugins
```
