# 0.93.3

Core 0.93.3 을 싣습니다.

**고친 것 — 세션을 다시 열었을 때 엉뚱한 대화가 실리던 것.**
- `/clear` 뒤나 세션을 다시 연 뒤 SCV 는 하던 일을 요약해 싣습니다. 그 요약이 "진행 중" 표시가 남은 가장 최근 대화를 골랐는데, 끝난 대화가 표시를 단 채 남고 실제로 일하던 대화는 계획으로 넘어가며 빠졌습니다.
- 이제 구현 중인 계획에 이어진 대화를 먼저 싣습니다. 없으면 최근 3일 안에 손댄 대화를 싣습니다.
- 3일 넘게 손대지 않은 대화는 전문 대신 경로만 알립니다. 대화 파일은 건드리지 않습니다.

**고친 것 — PR 도구가 묶음 계획의 가지를 늘 main 에서 만들던 것.**
- 묶음 계획(에픽)의 가지가 원격에 없으면 늘 main 에서 만들었습니다. 설정한 PR 대상과 원격의 기본 가지를 보지 않았고, main 이 없는 저장소에서는 커밋한 뒤에 실패했습니다.
- 이제 출발점을 PR 대상과 같은 순서로 정합니다: 설정한 대상 → 원격의 기본 가지 → main. 출발점이 원격에 없으면 커밋하기 전에 멈추고 이유를 알립니다.
