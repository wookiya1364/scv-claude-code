# 샘플 기획서 (DeckUI 추출 검증용)

DeckUI 추출이 실제로 빌드·렌더되는지 확인하기 위한 최소 markdown 원문입니다.
오른쪽 "기획서 원문" 패널에 이 내용이 그대로 표시됩니다.

## 문제 정의

markdown만으로 쓴 기획서는 읽는 사람이 화면·흐름·데이터를 머릿속으로 재구성해야 해서
이해가 느리고 오해가 생긴다.

## 목표 / 비목표

- 목표: markdown을 "기획서처럼" 보이는 덱으로 결정론적으로 변환한다.
- 비목표: 내용을 지어내지 않는다. 원문에 없는 값은 슬라이드에도 없다.
